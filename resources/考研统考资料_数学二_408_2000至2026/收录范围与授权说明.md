# 收录范围与授权说明

## 为什么仓库里是链接索引，不是整套真题 PDF

资料能在网页上打开或被搜索引擎收录，不等于允许第三方复制、打包、重新发布。公开仓库和安装包会把文件再次复制并分发；在没有明确开放许可、权利人许可或用户提供的可再分发材料前，本项目只保存原发布机构链接、年份与核验备注，不保存完整试卷、扫描件或答案解析。

这是一项保守的工程收录策略，不是对某份具体试卷权属的法律结论。若你拥有允许项目再分发的许可文件，请把许可范围、来源、期限和署名条件一并提供，再逐份核验后收录。个人学习中通过原发布页面访问，与将文件提交到公开 GitHub 仓库、随安装包发给所有用户，是不同用途。

## 内置讲义的性质

`seed/materials/builtin/` 中的数学二和 408 文档由本项目重新撰写：用自己的文字解释定义、方法、推导、易错点，并配原创例题。它们是复习导航与讲解材料，不是官方考试大纲原文，不是历年真题全集，也不代替目标年份的官方考试范围文件。

覆盖范围尽量按两门科目的常见课程主干展开；考试大纲可能按年份调整，特别是 408 的具体表述和数学统考细目。复习时先用当年官方招生/考试文件划定边界，再用本讲义补充理解。

## 反馈与扩充

发现某年链接失效、年份标错或来源权利不清，请在索引里提交准确的原发布机构页面。若要收录个人的题目分析，可以追加自己的考点标签和解题思路，但不要粘贴整道题干或商业解析的大段内容。

## 年度题号—知识点索引

项目内置 `exam_math2_<年份>_topics.md` 与 `exam_408_<年份>_topics.md`，只保存题号、简短考点标签和指向题目/标签页面的链接，不复制试题题干、答案解析或 PDF。数学二 2010—2025 标签整理自公开 GitHub 题库数据，408 2010—2026 标签整理自 CodeBrick 年度页；2026 数学二标签为人工按题干归纳。以上均为复习索引，未逐题与权威原卷/官方答案独立核对，不是官方标注，也不据此断言来源具有再分发许可。2019 年 408 第 46 题存在第三方分类重复，详见年度索引提示。
