# 数学二与 408 资料包（2000—2026）

此目录保留可追溯的考试范围说明、逐年真题来源索引和授权边界。`seed/materials/builtin/` 中包括项目原创讲义，以及不含题干/答案/PDF 的逐年考点索引元数据。

## 目录

- [真题来源索引](真题来源索引.md)：按年份列出当前找到的来源和缺口。
- [收录范围与授权说明](收录范围与授权说明.md)：解释为什么仓库保存索引链接而不镜像整套真题。
- [逐题核验状态](逐题核验状态.md)：区分已整理的第三方题号标签与尚未完成的原卷独立核验。
- [年度索引与本地文件更新（2026-09-27）](年度索引与本地文件更新-2026-09-27.md)：记录 Desktop 2010—2026 目录结构、PDF 来源/版本与 34 份内置索引。
- 项目自编讲义：`seed/materials/builtin/math2-core-guide.md`、`seed/materials/builtin/cs408-core-guide.md`。这些是原创讲解，不是官方大纲逐字转载，也不冒充真题解析。
- 年度索引：`seed/materials/builtin/exam_math2_<年份>_topics.md` 与 `seed/materials/builtin/exam_408_<年份>_topics.md`，2010—2026 每年一份。标签来自公开第三方目录；尚未对所有题目逐题独立核验，不能当作官方命题标签。
- [历年真题与知识树关联](../../docs/exam-question-reference-index.md)：说明考点节点、题号来源、导入方式及其与可练习题的区别。

## 范围

- 数学：数学（二），范围从 2000 年起；优先选用高校页面或高校文件链接。
- 计算机：408 计算机学科专业基础综合。当前可追溯的高校真题归档从 2009 年开始；2000—2008 年不能称为全国 408 统考真题。如需那些年份某所学校的计算机自命题卷，必须另按学校与科目整理。
- 2026 数学二 PDF 来自公开真题下载页，408 PDF 标注为回忆版；均不宣称为官方原档。个人复习目录中的文件来源及版本见 [桌面原卷下载核验](桌面原卷下载核验.md)。

## 进到应用内

先运行 `alembic upgrade head`，再运行 `python scripts/seed.py`。脚本会幂等同步内置资料，并从年度索引生成知识树考点节点和题号关联；启动后台 worker、等资料状态变为“可检索”后，才可以在问答的“内置资料”模式检索。仓库文件存在不等于数据库索引已经完成。项目仅内置考点标签与来源链接，不内置整套真题 PDF 或完整题干/答案。
