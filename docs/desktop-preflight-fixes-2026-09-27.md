# 安装包前缺陷修复与回归（2026-09-27）

本轮落实 `desktop-preflight-audit-2026-09-27.md` 的明确缺陷与测试门禁，不把 Web 项目等同于已完成安装包。保留此前工作区修改，不批量重写用户资料、不调用外部模型。

## 已落实

| 审计项 | 修改与回归 |
| --- | --- |
| B01 会话请求乱序 | 加载请求版本与当前会话双重检查；切到草稿使旧请求失效，读取期间禁止发送。浏览器延迟 A→切 B→释放 A 验证正文仍属于 B。 |
| B02 长引用与草稿丢失 | 检查问题+全部引用最终组合的 4000 字预算，超限不发送；收到 meta 前失败恢复草稿及引用。发送收尾同步结束后才允许下一次操作，避免恢复正文期间选取引用/再次发送的竞争。 |
| B03 失效会话全页错误 | 消息读取错误在问答页捕获并展示；旧请求的错误也不能覆盖当前会话。404 浏览器用例验证工作区仍可见。 |
| B04 DOCX 表格顺序 | 按 Word body 的段落/表格原序读取，解析器升级 docx-v2；回归检查第一章表格不会落到第二章之后。 |
| B05 解析资源无限制 | DOCX ZIP 总展开 32 MiB/2000 条目；正文 100 万字符；PDF 500 页；分块 5000 上限。DOCX/PDF 在独立解析子进程中执行，30 秒超时终止，不是仅停止等待线程。新增独立内容超限/解析超时安全错误码与中文提示。 |
| B06 跨站修改 | 非设置修改接口统一校验 Origin/Sec-Fetch-Site；允许同源和配置的前端来源。dev API 验证 loopback Host，防止任意 Host 同源绕过；设置接口保留原有更严格令牌保护。测试前端 5174 只在 test 环境默认放行。 |
| B07 第二实例取消回答 | 在启动恢复之前持有数据库级会话 advisory lock；第二实例明确拒绝启动。锁连接不长期停留在事务内，退出时显式释放并清理连接池，即使停止线程异常也会清理。 |
| B08 上传失败孤儿文件 | 保存后的 flush/入队失败回滚并清理文件；commit 失败以独立会话确认是否已经提交再补偿。无法确认提交结果时保留文件并告警，避免网络断开但服务端已提交时误删有效资料。 |
| B09 空白会话标题 | 创建、重命名、提问均先规范化空白再做 Pydantic 长度校验；纯空白拒绝，不存空标题。 |
| B10 测试目录隔离 | test 默认及 .env 开发目录改为数据库名关联的独立测试目录；上传/索引不得同目录。prepare_e2e_data 在 destructive 操作前还检查目录是否明确属于 test 路径，并拒绝项目根/祖先目录。 |

额外修改：根目录与 frontend 的 Docker 构建上下文排除真实 .env、密钥和不必要的构建产物；问答未配置模型提示改为前往设置，而不是修改 .env。

## 边界与下一步

- 防跨站保护不是生产登录/权限系统，也不是完整桌面 IPC/随机启动令牌方案；桌面壳仍需独立安全设计。`ALLOWED_WEB_ORIGINS` 可配置为 JSON 来源数组，新增前端域名必须显式配置；dev 仅接受 localhost/loopback 主机。
- 后端当前按同一数据库单实例运行，不支持多 worker 同时启动；以后若需水平扩展，应改成任务租约/所有权机制，不应直接删除此保护。
- 解析限额和子进程超时降低资源风险，但不等于完整操作系统内存沙箱；安装版的进程内存约束、恶意文档压力测试仍需验收。打包后要为解析 worker 配置独立可执行入口，不能只依赖当前 Python 的 `-m` 启动方式。
- 未在本轮扩展完整考研题库、改变长文档概述预算、改造大规模历史分页或实现跨机器会话分享。这些属于产品完善/容量工作，不应标成已完成。
- 桌面壳、后端 exe、数据库分发、用户数据目录、备份恢复、升级卸载、签名和清洁 Windows 安装验证仍未完成，详见审计报告。
- 用户原有开发后端未被重启：前端可热更新；后端代码需重新启动原有后端进程生效。启动时应保持单实例，不要并行启动另一个相同数据库后端。

### 本轮审计缺陷修复汇总

- BM25 关键词索引重建以锁保护并原子发布完整快照，避免并发期间记录、分词与分数错配。
- 检索线程设置单工作槽与真实 Future 完成后的槽位释放；断线/超时的 asyncio 包装取消不会错误释放仍在运行线程的槽位，新请求会明确快速返回可重试忙碌错误。
- 生产环境 Origin 只允许显式配置来源；移除把请求自身 Host/base URL 混入白名单的逻辑。实例 advisory-lock 连接增加保活，失锁时停止作业并对 API 返回安全 503。
- 非 Windows 不再明文保存设置密钥；无法安全加密时密钥写入 fail closed。资料路由统一转换向量/embedding 故障；reindex/retry 对已有活动作业去重。
- SSE 未预期异常持久化部分正文与有效引用后发送安全错误帧；上传可由用户取消浏览器请求并解释已完成的服务端接收可能无法撤回。
- 前端修复设置刷新清空未保存密钥、KeepAlive 会话路由失同步、资料搜索后不轮询/阅读器闪断、学习页后台刷新覆盖做题内容、会话切换假空态及答案加载互相覆盖。
- 已修复的具体问题、边界和实现证据见当前工作区差异；无已知零缺陷保证。
