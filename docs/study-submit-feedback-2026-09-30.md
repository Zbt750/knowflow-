# 作答反馈与主动继续

本轮根据用户体验反馈调整：

- 正确/错误只在题目旁显示 ✓ / ×，同时保留屏幕阅读器名称；未知与空白分别显示未判定/未作答，不误标错误。
- 删除提交后的掌握度、旧自评和毕业进度长提示。后端证据、错题复测安排没有被删除，知识树仍可查看。
- 专注模式提交后保留当前题。锁定已保存答案与选择，仍可展开/收起解析；点击下一题才进入下一道未完成题。最后一题保留解析，点击完成回看后进入完成空态。
- 全卷不会切走当前题，结果符号刷新后保留。
- 过程审阅的反馈、忙碌状态、内容类型与重试键提升到页面状态，切换视图不重置正在执行的请求，网络失败后跨视图重试也复用键。

本轮不改变自动判题、掌握度或毕业规则。图片识别仍延期。
