# 真实前端问答回归

此测试通过系统 Chrome 打开 Vue 页面、切换范围、填写并发送问题，读取真实模型 SSE，
检查错误帧、完成状态、实际会话模式、刷新后的正文和浏览器异常。不是接口 mock，也不是 RAGAS 裁判评分。

只使用获准的《高等数学核心考点讲义》《阶段A验收笔记》，隔离 PostgreSQL schema、
上传目录与向量索引。不读取真实用户资料。调用当前配置模型会产生费用，须获得授权后执行。

先启动隔离环境：

```powershell
python scripts/run_isolated_chat_ragas.py --serve-ui --ui-seconds 900
```

再在 frontend 目录运行：

```powershell
$env:E2E_LIVE_CHAT='1'
$env:LIVE_CHAT_ROUNDS='2'
npx playwright test --config playwright.live.config.ts
```

每轮包含六条资料问答及整份讲义逐节细讲，共十四条。报告保存于
`eval/reports/live-chat-latest.json`，失败截图按时间分目录保存。
初始加载完成后才允许新建/切范围/发送，避免历史恢复覆盖用户刚选择的范围。
隔离服务到时自动停止、清理本次 schema 和索引，并验证共享资料 ID 没有变化。

## 输出上限恢复协议

成功帧类型保持 `meta → delta* → citations → done`。普通 delta 追加正文；
当第一轮 `finish_reason=length` 时，发送一个 `delta`，包含 `replace=true`、
`recovering=true` 和保留的来源前缀，清除半截正文并显示恢复状态。
第二轮重新生成完整回答，seq 始终递增，done 提供最终规范化正文。

仅恢复一次，预算至少翻倍。一般网络故障在已有正文时不重试，避免无规则重复。
详细回答和恢复轮次的总时限最多 180 秒，网络静默仍遵守配置 timeout。
二次失败仍发送 error，保留失败正文、耗时和 error_code；不得落库为 completed，
不得把失败片段作为可用引用。

回归测试同时覆盖成功恢复、两次截断、正文替换、前缀保留、seq 单调递增及失败内容落库。
真实模型能完成这些样例，并不等于所有问题的准确率、完整率已经通过 RAGAS。

## 2026-09-27 最终实测结果

- 当前配置模型，系统 Chrome，真实 Vue 前端、真实接口、两份隔离测试讲义。
- 两轮十四条问题全部通过，实际会话模式正确；没有 error 帧、未捕获页面异常或刷新正文丢失。
- 六种基础问答每轮一次，另各有一次整份内置讲义细讲；最后两次细讲约 2970 / 3254 字，
  分别耗时约 16.1 / 15.6 秒。本轮最长约 46.7 秒，不能宣称所有回答都快。
- 这十四条最终测试没有触发输出上限；此前独立压力调用曾真实触发一次恢复，
  最终约 2725 字、69.8 秒，证实模型上限后的重生成路径实际工作。
  该压力调用在初始化竞态修复前落到“我的资料”范围，不计为内置资料模式通过证明。
- 后端 187 条独立 schema 回归通过（跳过迁移），前端 21 条单元测试通过；
  typecheck/build 通过，另 1 条明确 mock 的正文替换/刷新回归通过。
- 中途测试定位错误、模式竞态及详细回答总时限失败均未计为通过；最终 JSON 保存最后一轮。
- 未重跑全量 pytest、全量 E2E 或四项 RAGAS，不复用旧评分来声称准确率上升。
