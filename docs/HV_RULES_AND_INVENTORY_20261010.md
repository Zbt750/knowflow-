## 3. 尚存毕业规则：实际代码语义与数量

### 3.1 可信证据底线

`backend/mastery/origin_evidence.py`的v2证据门槛要求当前公共题、答案/题面信任与版本hash匹配、可信答案依据、受支持的确定性判分、有效作答收据、独立且非辅助的正确作答，并排除猜测/“不知道”、个人生成批次及不可信答案一致性结果。`policy_confirmation_window()`按Question ID只保留最新有效确认，避免同题反复提交凑独立题数。

`backend/mastery/attempt_sequence.py`将`first_independent_correct`列为有效的独立正确类别；提示、解析、过程审阅后正确、立即自行改正、低置信度以及历史独立性不明均不作为同等级确认。`backend/mastery/evidence.py`将这些辅助正确保留为部分/弱学习信号，而非可信失败或确认。这与“第一次独立正确可作为证据、解析后正确需要后续验证”的原则基本一致。

### 3.2 284条策略现状

以下分布来自隔离策略副本移除来源配额后的284条策略快照，不是新设计建议：

| 现存条件 | 当前分布 | 当前作用与风险 |

策略版本：v2有279条；v1有5条。v1具体是隐函数求导、等价无穷小替换、洛必达法则、等比级数敛散性与求和、行列式性质；每个均要求多题、至少1道变式、跨2天、两个技能标签和题型覆盖。其余279条v2策略中，196条为“3次确认/3道不同题/跨2天”，17条为“2次/2题/跨1天”，66条为“1次/1题/当天允许”；279条都要求一个与节点名相同的标签。

因此：代码允许第一次独立正确成为有效证据，但大部分知识点仍不可能凭单条证据毕业——这是现存固定策略的实际结果，不是题目资格问题。不同题数与确认数重复、固定跨天门、机械技能/题型/变式门槛都需要逐项判断是否适用于某个知识点。

### 3.3 毕业门槛如何驱动今日选题

`backend/mastery/rules.py`中的`graduation_check()`和`analyze_gaps()`把确认数、不同题数、题型、变式、技能及跨天跨度全部作为硬缺口。`backend/mastery/selection.py`再按这些缺口挑题；优先级包含未掌握类型、部分掌握类型、必需题型/技能/变式、到期复测、未做题及最久未复测题。跨天跨度不足时，旧题可被再次安排以拉开跨度。

这使“毕业政策”同时承担了两种职责：识别掌握证据，以及生成复习任务。用户提出的新原则要求把这两者分开：错题、薄弱技能、解析后完成、间隔复习和变式题应作为学习驱动信号，是否安排由证据风险、题库及奶蛙计划共同决定，不应一概转成每个用户都要完成的毕业条件。

当前`transition()`遇到可靠客观错误会将当前毕业确认窗口清空并转为`STUCK`，但不会删除Attempt/LearningEvent历史；后续正确证据可以重新积累，因此错误不是永久封锁。不过它会让先前仍可信的正确证据不再参与当前毕业累计，是需要审视的“全窗口重置”行为。应考虑把错误变为对应能力的风险/巩固信号，而不抹去其他能力已获得的有效掌握证据；若答案被撤销或题目版本失信，则仍须按证据有效性失效规则处理。

## 4. 建议的规则调整方向（尚未实现）

建议保留“证据可信性守卫”，把“学习计划建议”与“毕业硬门槛”拆开：

1. **毕业证据资格不放松**：只有答案与内容版本可信、判题受支持、用户独立作答、非个人AI题且非重复题证据，才可作为有效掌握依据。解析后正确/提示后正确记为学习进步并引出后续独立验证；AI一致性仅能提供带说明的练习反馈。
2. **门槛按核心能力定义，而非统一配额**：题库/教学切片为每个叶节点声明真正不可替代的核心能力。窄且低歧义的能力可由一次可信独立正确提供初步掌握证据；范围广、易混淆或复合技能节点，需要覆盖未被证明的核心能力。不要仅为达到固定数字而重复同类题。
3. **复习动作由风险触发**：错误、解析后完成、低置信度、近似题重复失败、证据时间较久或技能缺口可以提高复习优先级、安排解释/变式/间隔复测，但不自动等同于毕业失败，也不机械要求人人隔天做题。
4. **保留进步与历史**：一次错误应标记相关能力需要巩固，不应清空其他能力的可信正确证据；用户经针对性学习后新的独立验证可以解除风险。答案/题面信任失效是证据有效性变化，应区别于学生答错。
5. **毕业后继续学习**：毕业表示当前核心能力已有足够可信证据，不是停止学习。现有毕业后风险和熟练度投影继续独立运行；后续复习可以更新熟练度，但不得改写最初毕业事实。

以上为规则方向，不是本轮代码变更。需要结合各知识点核心能力定义和题库准备情况形成规则版本，再用“简单单技能、复合技能、错后掌握、解析后掌握、答案撤销、毕业后回顾”等隔离场景验收。不能统一改成“一题即毕业”，也不应继续把当前每个配额机械保留。
