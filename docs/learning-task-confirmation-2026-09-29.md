# 学习任务：用户确认与今日卷联动

本阶段在只读 Agent 草案上增加显式确认，不新增模型写入工具。

## 行为边界

- 新增 POST `/api/learning-tasks/{task_id}/confirm`，请求必须携带本轮 `draft_version`。
- 新草案 `can_commit` 表示有在线题、可以由用户确认，不代表 Agent 拥有写权限；旧草案仍会重新校验。
- 没有今日卷时创建一张；已有活动或已完成的今日卷时，复用现有追加服务添加到卷尾，不重排、不覆盖作答。
- 题目与确认回执同一事务落库。任务行锁保证同一任务重复及并发确认只执行一次；回执保存在任务 metrics 的 commit 字段。
- 确认前重新检查版本、状态、题目活动性、节点归属、可考核状态、题型限制、基础题限制、时长与今日重复题。
- 同一任务确认后不允许取消或修改其回执；再次安排创建新任务。取消不删除已加入的题目。
- 不写掌握度、毕业状态、作答记录；不把原卷引用当作在线题。
- 只有知识复习的草案没有确认加入按钮，也不会创建空卷。知识复习保留在草案中，目前不作为独立今日任务落库。
- 今日日期使用上海时区；重复确认返回原回执，不会跨天重复添加。
- 与普通生成卷同时创建发生唯一性冲突时，事务全部回滚，返回 409，用户刷新后重新校验。

## 前端

内置资料模式中的默认收起入口保持不变。草案添加“确认加入今日学习”；输入目标或预算已修改时禁用旧草案确认。提交后显示已加入并提供“去做题”。私人资料模式保持资料问答。

## 验证与限制

专项集成测试使用隔离 PostgreSQL 和协议模型替身，覆盖确认、幂等、并发、已有卷、取消、旧版本、题目停用和预算变化；浏览器测试验证确认按钮与跳转。

真实模型规划质量尚未评测，不以工程测试代替真实 Agent 质量验收。未发送私人资料，也未新增收费评测调用。当前单用户本机项目的访问控制边界不变，不宣称多用户授权隔离完成。
