# 客观掌握度增量升级（2026-09-29）

本阶段接续 `answer-submission-upgrade-2026-09-29.md`，该文档中“机器作答不累计毕业”的历史限制由本阶段的客观证据规则替代。没有改写旧作答历史，也没有建设 Agent。

## 证据边界

- 仅经过核验且判题支持的最终答案进入客观证据状态机。目前已核验种子题仅三道，不能据此声称整个数学二和408题库都可自动判题。
- 独立正确确认按不同题去重，继续使用知识点原有的题型、考法、变式、跨天等毕业条件。最终结果正确不代表证明、推导或程序过程正确。
- 查看过解析、明确选择“猜的”或“完全不会”的正确结果只记录辅助信号，不增加独立确认。
- 答错只撤销该题的确认，保留其他题的确认，记为待复测；复测正确才解除该题待复测。其他题答对不能绕开它。
- 空白、未经核验、无法比较的表达式、证明及程序题不猜分，不凭此修改掌握状态。
- 首个可靠结果将节点渐进切换到 `objective_v1`。切换前的完整掌握快照保存于本次不可变作答证据中；旧事件和旧作答保留。不批量将旧自评换算成正确率。
- 客观模式下的节点/题目自评只作辅助，不领取基础确认，也不清空客观成果。未切换节点仍保留原兼容自评规则，界面明确标记历史自评依据。
- 本功能不是监考系统：跟踪的只是新界面的解析查看，外部资料及旧只读答案接口无法完全观测。

## 工程实现

- `KpState` 新增依据类型和待复测题号；迁移 `d04f6c21be39` 保持原数据。

- 今日练习选题优先包含待复测题，但仍受时间预算限制。知识树显示依据及待复测数量。
