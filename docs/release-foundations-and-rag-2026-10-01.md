## 真题接入：先核验再导入

`scripts/audit_exam_pdf_intake.py` 对桌面已有资料作只读检查，结果见 `exam-pdf-intake-2026-10-01.json`。数学二、408 的 2010—2026 年共 34 个年度目录均有 PDF，共 35 份文件；19 份具有可提取文字候选，16 份需要 OCR 或人工处理。该报告不保存全文，不证明公式、图表、答案、逐题数量、节点关联或复用权利正确。文字候选中的异常字形仍须人工核对。

`backend/services/question_pack.py` 和 `scripts/import_reviewed_questions.py` 接入人工核验题包：来源与复用依据、核验人员/日期、题干、答案、解析、题型、技能标签和节点都是明确字段。只绑定有效可考核叶子节点；来源 ID 幂等，不覆盖已有题或学习记录；发现冲突、重映射或批内坏项整批拒绝。PostgreSQL 事务级锁串行化同题包导入，节点锁采用稳定顺序。只支持现有可靠单选/单一数值判题，证明等开放题不能因此变成自动判分题。

默认只读预览：

```powershell
python scripts/import_reviewed_questions.py reviewed-pack.json
# 核验输出、备份后才显式写入
python scripts/import_reviewed_questions.py reviewed-pack.json --apply
```

来源字段是人工声明，不是自动版权鉴定。原卷引用与在线题分别保留；向仅原卷引用节点导入在线题时返回 `requires_online_policy_review`，不偷偷改变节点考核或毕业策略。本轮没有把未经核验 PDF 自动导为真题，也没有新增真实 408 在线题。题包格式由 Pydantic `QuestionPack` 定义；提交后的来源存于 `grading_config.provenance`。
