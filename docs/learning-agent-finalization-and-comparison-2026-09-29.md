# 学习任务收口与规则对照

## 本轮产品修复

1. 明确精确题数（如“必须有3道”“恰好三道”“只做2道”）进入后端校验，同卷重复题不能凑数；不是任意自然语言数字解析器。“推荐三道”“三到五道”不当作硬要求。
2. 精确题数未满足时，根据实际无有效草案的状态返回可执行选择：减少题数或确认放宽题型、范围、时间；不建议在同卷重复同题。
3. 有排除范围的有效方案，面向用户的说明和草案理由由校验后的题数、时间、范围构造，不能沿用模型把排除分支说成不存在/零题的解释。此类说明刻意不保留未核验的自由理由；其他场景仍需人工核对模型解释。
4. “不限题型”不再删除范围上下文，只解除之前的题型要求，明确的新题型要求仍优先。
5. 最终回复允许完整 JSON 或单个 JSON 代码块，不从任意自由文本中截取对象。格式不合法时使用剩余的原六轮/60秒预算纠正，不重新开放写入权限或无限重试。最终仍失败时给出格式错误提示，不要求修改正确的学习目标。
6. 记录最终协议校验的轮次、字段和错误类型，不记录原始输入或完整回复；评测报告增加 error_code。
