# 文件追问与跨文件分类收口（离线阶段）

承接v3.1真实复测。该次报告对应chat-evidence-v3，不覆盖原始答案与分数。本轮只改实际检索范围、提示词任务约束和裁判诊断记录，**没有新的模型或RAGAS真实调用**。

## 修复

- 文件结构指代（如“它后半部分的E、F、G”）继承最近用户明确点名的资料，不从历史模型回答猜文件。已验证解析所得的`material_ids`进入`SearchFilters`，返回证据和最终prompt均只含指定文件；有多份历史文件且当前用单数指代时要求用户确认，不能把全部文件一起读入。
- 跨文件“共同／各自独有”改按具体事实分类。原来的“全文覆盖清单”与“逐章概述”会推动模型在结尾把整段A–G笼统归为独有；现在仅对事实分类型比较停用该概述指令，普通全文概述仍逐章覆盖。比较按共同项、各文件特有项结束；一个阶段混合共同和独有事实时不能整体标独有。提示词版本升为`chat-evidence-v4`，证据快照版本不变。
- Context Precision仍用原评分公式和现有裁判调用。诊断记录每块的顺序、二元verdict、有限理由，并标记诊断是否覆盖全部上下文；失败或超时时保留已得到的诊断，不把部分诊断伪装成完整评分。普通应用不启用证据快照，诊断只供隔离评测使用。

## 验证

专项单测覆盖：单数/复数历史指代、重名歧义、文件过滤器到prompt的链路、比较/普通概述指令互不干扰、裁判部分诊断与失败保存。数据库恢复后，问题用例加专项39项通过；最终后端全量**770项通过**，compileall和diff检查通过。本轮未跑浏览器E2E或真实模型复测。

## 边界

离线回归证实检索范围过滤与提示词组合，**不证实模型在真实跨文件回答中不再误归类**，也不能重写v3.1原始Precision=0的三条结果。后续若获新的有限授权，再用相同隔离合成资料对文件追问与共同/独有比较定点复测，同时读取逐块裁判理由；未授权前不自动发起收费评测，也不扩大到新Agent或批改功能。
