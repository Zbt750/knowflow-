# 实际证据评测接入

本轮交付是评分依据修正，不是新的检索策略，也不是质量分数提升证明。

## 开关与隐私

`CAPTURE_TEST_EVIDENCE` 默认 false。启用时必须 `APP_ENV=test` 且满足既有测试数据库、存储隔离保护；开发/生产启用会拒绝启动。隔离评测启动器自动为子进程启用，普通服务不启用。

完成及已准备上下文的失败流式回答，其 metadata 保存最终 prompt 的逐片段证据，不重查资料。快照含版本、消息 ID、模型请求标记、来源映射、资料名、章节和原文校验和。不保存完整问题、历史、系统提示或密钥。快照含测试原文，测试库和评测产物仍须按受控资料管理；不是脱敏后的公开数据。检索前失败或取消请求不保证保存快照。

消息恢复接口仅在测试开关开启时返回快照。RAGAS 用 done 的消息 ID 查找该轮快照，核对 v2 版本、ID、顺序、来源映射、块正文和拼接校验和。不存在或失败就记录案例错误，不退回重新检索。无资料的通用回答有合法空证据；中断或失败回答不评分。校验和用于检测一致性，不是签名或访问控制。

## 当前限制与下一步

v2 已从上下文构造阶段显式记录每块边界，`contexts` 与真实片段一一对应，拼接后必须等于最终提示词证据正文。正文内的伪 `[C2]`、标题、代码和空行不会被用来猜分块。跨文件、长文概述均记录经过最终裁剪后进入提示词的内容。禁止把旧 v1 整包评分和旧重检索评分直接当成 v2 的改进证据，需要重新建立基线。

后续已补答案生成的流式 usage、提示词版本、逐轮耗时与重试记录，详见 `chat-generation-observability-2026-09-29.md`。仍不包含所有辅助调用和完整检索阶段追踪。下一步用授权范围内的隔离资料建立新评测基线，不把记录完整度当成回答质量提升证明。
