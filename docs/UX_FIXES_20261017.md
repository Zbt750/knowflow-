# 用户体验问题处理清单（2026-10-17）

本清单记录本轮实际实施的修复，不是新的开发阶段，也不代表重新完成全库内容审核或真实模型验收。工作区原有大量未提交修改均予以保留。

## 已实施的行为变化

| 问题 | 实际处理 |
| --- | --- |
| 问答页出现资料依据、引用片段、引用编号 | 移除答案来源说明、归因区、引用展开列表等前端展示；普通正文中的 `[C数字]` 标记不再显示，代码、数学和正常链接不受影响。后端引用证据和历史元数据仍保留。 |
| 做题结果不显眼、提交后还能重答 | 专注和全卷模式显示明确正误及锁定提示；同一 PracticeItem 提交后不能另交答案。网络丢失响应时同一幂等键可恢复原结果，不额外产生作答。后续新的复习练习实例不受影响。 |
| 专注模式顶部文案和右侧空白影响做题 | 移除已生成卷的大标题说明；助手、追加练习和进度使用题目上方工具区；题目及答案纵向排布，不再预留空的答案侧栏。 |
| 学习助手输入发送后滞留、输入体验不顺 | 发送即清空已发送文本，失败时在不覆盖新输入的前提下恢复；输入框自动增高并限制高度，处理中文输入法回车。 |
| 点击深入问答就生成会话记录 | 点击仅保存浏览器临时草稿并跳转。第一次真正发送时才创建对应后端会话和上下文；新对话不会串用旧草稿。 |
| 生题前没有确认知识节点 | 请求先返回明确的知识节点确认卡，不调用模型、不生成题目。确认后才走已有质量检查和保存流程。明确解释暂不支持的题型和节点范围。 |
| 生成等同于加入今日学习 | 保持生成后保存、展示结果，再由用户选择加入或暂不加入。没有今日计划时仍需明确确认；重复加入保持幂等。个人题仍不能作为正式毕业证据。 |
| 知识节点难点、展开后不易收回 | 整行节点可选中并切换展开/收回，独立展开按钮保留；增大点击区域；修复深层子树及多根节点的纵向重叠。 |
| 树形奶蛙偏细 | 基于现有素材调整横纵比例，让身体更饱满；本轮没有重新绘制一套一比一忍者动作、多肢体角色。 |
| 资料搜索对话边界不清 | 回答增加小奶蛙头像、角色名、背景和边框，区分用户与助手。 |
| 公式显示成围栏、裸 LaTeX 和等号分隔线 | 增加 math/latex/tex 围栏和可识别的异常公式块规范化，交由 KaTeX 渲染；回答格式指令约束正确数学分隔符。不会擅自更改公式数值或改写历史答案。 |
| 输入框太方 | 文本输入、选择和多行输入统一圆角；聊天输入容器采用圆角，不改变复选框等特殊控件。 |
| 来源标签容易混淆 | 沿用真实来源映射区分真题整理、真题改编、开发原创及个人 AI 练习；不因视觉统一而将个人题改为正式题。 |
| 奶蛙姿势与轻动效 | 不同场景使用已有相应姿势；保留轻微呼吸、眨眼及持物动作，遵守减少动态效果的系统设置。未承诺所有历史图片均已重新制作独立骨骼动画。 |

## 运行与数据边界

- 测试写入仅在随机高端口的自有隔离 PostgreSQL 中执行。最终运行端口50822，运行记录确认测试实例已正常停止、自有临时数据已清理，原数据库集群未被测试运行器触碰。
- 没有真实付费模型请求，没有迁移、seed、题库导入或毕业算法修改。
- 沿用用户此前允许仅重启项目8000后端的授权，重启同一项目应用进程，使新接口及提交保护生效。未重启 PostgreSQL。
- 重启后只读健康检查返回 `status=ok`、`database=connected`；运行中 OpenAPI 的 `AssistantRequest` 已包含 `personal_generation_confirmed_kp_id`。
- 应用正常启动包含自身的未完成聊天恢复逻辑，不应将此表述为“启动过程完全没有数据库操作”。本轮修复脚本没有改写真实 Question、Attempt、LearningEvent、KpState 或毕业事实。

## 尚未声称完成的事项

1. 未新增真实 DeepSeek 复测；离线及浏览器通过不等于模型回答质量全部通过。
2. 本清单初次交付时生题仅开放已有可靠校验器支持的节点。随后按用户“全部知识点能够生题”的明确要求，已取消默认AI出题的固定节点白名单，新增不冒称独立核验的个人参考题通路。详见 `PERSONAL_GENERATION_ALL_NODES_20261017.md`；正式毕业资格未放宽。
3. 忍者参考动作的一比一多肢体全新美术素材没有在本轮重画；完成的是现有树形角色比例和知识节点交互修复。
4. 未根据“30题没有大题”的观察新增固定题型配额或修改推荐/毕业规则；这是独立的题库供给与选题问题，不伪称已解决。
5. 本轮隐藏引用仅是问答展示调整，不删除资料检索、来源证据或审核记录；不保证模型在所有未来回答中绝不自然提到资料。

建议用户刷新页面后按实际顺序检查：今日学习提交一次答案 → 查看明确结果与锁定 → 打开奶蛙并发送 → 点击深入问答但暂不发送 → 发起生题并确认节点 → 生成后选择暂不加入/明确加入 → 知识树展开与收回。
