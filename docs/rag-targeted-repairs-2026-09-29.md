# v3 基线后的定点修复

本轮针对 `rag-baseline-v3-2026-09-29.md` 的坏例，未重做检索架构、未增加模型调用，也未修改历史结果。

## 产品侧

- 文件简称：仅在明确的“文件／资料／文档”指称中接受标题的字面尾部简称，至少四字符。泛词、拼写猜测不用于自动选文件；多个文件共享简称仍保持歧义，完整标题优先。示例“阶段说明这份文件”可定位“合成项目阶段说明”。不宣称支持任意语义简称。
- 追问：历史用于指代，不扩大当前提出的章节范围。
- 跨文件比较：两份共有事实只归共同项，章节名不同不代表内容独有，结尾不能重新混淆分类。
- 通用知识：限定算法结论的对象和条件，负环对某个目标的影响还需负环可达该目标，避免把部分目标的无界距离说成全部目标无定义。
- 提示词版本更新为 `chat-evidence-v3`；实际证据格式仍为 v2。基线清单从同一版本常量读取，避免记录漂移。

## 评测侧

- 独立 `chat_baseline_v3_1.jsonl` 修正连续／可导的等价措辞、隐函数非零的公式措辞、范围隔离场景类型；跨文件参考答案不再把共有的 F 阶段持久化列为独有。
- 范围隔离判定必须同时满足模式提示和无禁止内容泄露。
- 铺垫问题记录检索模式及是否得到非范围提示响应。该标记只是流程诊断，不证明文件内容正确；与最终答案指标分开保留。
- 目标或铺垫失败时，在删除会话前按 SSE 的本轮消息 ID 恢复生成记录。仅合成受控基线保存完整证据和部分正文；普通评测不扩大资料保存范围。找不到消息／恢复接口失败独立记录，不重问、不对失败回答评分。
- 首次正文时钟改为检查累计文本，排除 Markdown 标题及拆分的通用参考前缀。这仍是近似文本计时，不能当作语义首句完成时间；不重算旧报告。
