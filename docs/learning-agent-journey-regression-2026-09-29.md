# 学习 Agent 到作答证据的跨模块回归

## 本轮交付

新增 `tests/integration/test_agent_learning_journey.py`，使用隔离测试库、真实 API 和协议模型替身，不发送私人资料，也不产生模型调用费用。

每个场景完整经过：已有一张已完成今日卷 → 创建学习任务 → 生成草案 → 修改为五分钟填空题方案 → 拒绝旧版本确认 → 确认追加 → 重复确认 → 提交答案 → 重复提交 → 检查知识状态 → 检查下一日推荐。

六种答案情况：正确分数、错误数值、查看解析后答对、猜对、空白、暂不支持的表达式。

检查旧作答与顺序不变、确认前不写卷、追加后卷重新激活、重复操作不重复生成题目或作答事件、已确认任务不可取消、客观错误进入复测、辅助和未知结果不产生有效掌握确认，以及 Agent 状态工具可读取结果但不泄露原始答案。

## 规则核对

初次测试中三条断言与现有规则不一致，核对状态机和推荐服务后修正测试预期，而非改业务代码迎合测试：

- 客观错题的推荐原因是 `objective_review`，不是旧自评的 `not_mastered`。
- 空白和无法可靠判定的提交只记历史，不将节点强制切换为 `objective_v1`。
