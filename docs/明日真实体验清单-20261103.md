# 奶蛙真实体验清单（2026-11-03 早）

> 用法：照着从上往下走，每条做完在「实际」列写一句话，体感列打勾。
> 不是"点一遍看看"，每条都有**判据**——没判据的体验等于白体验。
> 总预算 40 分钟；只有 15 分钟就只做【主线】标记的 5 条。

---

## 0. 一条红线（先看这个）

**不要在今天的正式卷上问「为什么这个知识点没毕业？」「这个知识点为什么还没学完？」**

原因：这句话会被判成"要看答案"，系统会把**当前那道题**标记成"已看过答案"，并写一条 `qa_assistance_used(level=solution)`。后果是这道题今天就算你独立答对，也不算独立答对，不进毕业进度。

这是本轮唯一一个 P1（NB-15），已定位到 `assistant_router.py:341`，还没修。想验它的话，等修完再用一道不重要的题试。

其他别碰：批量出题（烧 token）、设置页改模型配置、任何"清空/重置"按钮。

## 2. 冻结机制（【主线】，本轮最高价值）

卷生成后就该锁死。这一组上一轮因为"会改正式卷"没测，明天可以测——因为改的是你刚造的卷。

| # | 动作 | 判据 | 实际 | 体感 |
|---|---|---|---|---|
| 2.1 | 在聊天里说「再加两道题」 | 应明确拒绝：今日卷已生成并冻结 | | |
| 2.2 | 说「把今天预算改成 60 分钟」 | 应拒绝，或明确告知只对下次生效 | | |
| 2.3 | 说「删掉第 3 题」 | 应拒绝，并说明理由 | | |
| 2.4 | 界面上找"删除/替换"入口 | 冻结态下应不可用或点了有明确提示 | | |

**重点看**：拒绝的时候是**说人话**，还是只弹个"操作失败"？后者算缺陷。
**已知风险**：上一轮发现过"删一道题 → 11 道压成 3 道"、"只改预算 → 11 变 3"的历史问题，如果 2.2/2.3 之后题数变了，立刻记下来并截图。

## 7. 记录表（复制到手机备忘录）

```
时间 | 我做了什么 | 预期 | 实际 | 体感(顺/别扭/错)
-----|-----------|------|------|----------------
```

**判断标准**：
- **顺** = 不用想就知道下一步，结果符合预期
- **别扭** = 能做，但要试第二次 / 文案看不懂 / 要多点一步
- **错** = 结果不对、没反应、数据变了、答非所问

只有"错"值得截图。"别扭"用一句话记就行——这类最容易被忽略，但最影响日常。

1. 把"错"的条目数一下，看有没有**数据被改了**（题数变了、卷被重建、作答丢了）。有的话立刻停手，先告诉我。
2. 把记录表发我，我对照代码定位——有具体复现路径的，我能直接给出源码位置和改法。
3. 如果 2.x 那组发现题数被改，**先别继续用**，那是数据完整性问题，比体验问题严重得多。
