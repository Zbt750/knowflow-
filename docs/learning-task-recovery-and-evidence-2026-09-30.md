# 学习任务恢复、错题证据与知识资产检查

## 本轮交付

1. 学习状态工具返回真实作答日期，待复测题明确标记为 `pending_review`。查题在16条候选限制之前优先排序待复测题，仍按节点及题型过滤；最终方案继续受预算、今日重复题、范围与题目可用性校验约束。用户自述弱项不转换为客观错题，不输出标准答案或原始作答正文。
2. 学习任务进度使用串行轮询，每次请求结束后再安排下一次；连续三次读取失败后停止并提供只读刷新。运行或确认响应丢失时先读取已保存任务，不重新调用模型或重复写卷；手动刷新不覆盖未保存的目标与时间修改。取消及切换会话后，迟到的进度响应不能覆盖新状态。
3. 草案保存题目 `updated_at` UTC版本。确认事务锁定题目后检查版本，题干、答案、解析、选项、判题配置、难度等经ORM修改后，旧草案返回409并要求重新安排。已提交任务仍返回原幂等回执，不因后来改题重复加题。未提交的旧草案若没有版本字段，需要重新生成。无需数据库迁移。
4. 资产只读报告增加节点题目难度、考法标签缺项、真题年份和异常绑定统计。判题覆盖报告只统计启用考核节点的启用题，排除停用题及汇总节点。结构检查不自动证明题目关联正确、讲解正确或官方范围全部覆盖。

## 验证方式

- PostgreSQL集成测试：答错→待复测→Agent读取，16条候选限制前排序、损坏历史ID、题型限制、改题后拒绝旧草案、重复确认。
- 浏览器协议测试：运行/确认丢失响应，手动刷新保留编辑，进度连续失败后恢复，以及已有的取消竞态、会话恢复。
- 前端类型检查、单元测试、构建；资产结构单测；最后全量后端和浏览器回归。最终执行结果在构建记录D-88记载。

## 明确边界

本次开发库只读盘点：304个启用节点，与当前版本化种子范围一致，讲解缺失及标题结构缺项均为0；22道在线题中14道支持核验判题，8道需人工对照或未核验，已标记核验却配置无效的题为0。2673条原卷关联对应1184个去重题号，66条关联没有来源URL。279个考核节点只有原卷引用，408的185个考核节点没有在线题干。题目挂在停用/非考核节点、原卷引用挂在停用节点的异常统计均为0。

完整机器可读报告见 `knowledge-assets-audit-2026-09-30.json`。这些数字不证明官方数学二/408全部知识范围、2010年至今逐年真题完整性或逐题关联正确；后续内容补齐须使用可合法复用的题干、答案与核验记录，不能生成伪真题凑数。

- 版本依赖写入流程维护 `updated_at`；手写SQL绕过更新时间不在这一检查保证内。原有已生成练习卷也没有改为题目全量内容快照。
- 手动刷新只是读取任务，读不到服务器时保留当前表单，不声称取消、确认或运行已经成功。
- 待复测优先是候选排序，不强迫模型选题，也不自动清除复测标记；只有既有可靠作答证据规则处理掌握度。
- 本轮没有新增收费模型质量评测，工具协议回归不能证明真实模型规划准确率提升。
- 图片审阅、任意代码执行、长期计划和安装包仍属于独立后续路线。
