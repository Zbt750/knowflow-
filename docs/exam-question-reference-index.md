# 历年真题与知识树关联

知识树现在可以按节点查看 2010—2026 年数学二与 408 的年度题号索引。该数据由 `seed/materials/builtin/exam_math2_<year>_topics.md` 与 `exam_408_<year>_topics.md` 中的题号、简短考点标签和来源链接生成。

## 关联方式

- 每个考点标签进入对应科目分支下的“历年考点”节点；数学标签按高数/线代领域归组，408 标签按数据结构、计算机组成原理、操作系统、计算机网络归组。
- 一个题目有多个分号分隔的考点标签时，会分别绑定到相关节点。节点详情的“历年真题”页签按年份列出题号、原标签、外部来源和桌面年度文件夹位置。
- 精细标签之外另有“专题汇总”节点：把同一课程大类下的来源标签汇集，方便从一个专题连续挑选多年份题目。专题记录保留原标签、题目链接和年份；同一原卷题在同一专题只出现一次，不会复制题干或伪造新题。精细考点节点与专题节点分别记录掌握证据，专题做题不会冒充某个更细节点已掌握。
- 对应标签与项目已有知识点完全重合时，优先绑定到已有节点，避免同义节点重复。
- 来源没有给出标签的题目会进入“待核对：来源未提供考点标签”，不推断具体知识点。2019 年 408 第 46 题在第三方分类中的跨学科重复归类原样保留。

## 与练习题、毕业证据的关系

这些记录本身仍然只是题号与来源索引，`exam_question_references` 不存题干、选项、答案或解析，也不会伪造成可在应用内作答的 `Question`。不过，带具体考点的索引叶子现在是可考核节点：用户可以从知识树把对应的原卷任务加入今日学习，打开外部题目来源或桌面原卷完成后按真实表现自评。标记“已掌握”的不同真题作为该节点的毕业证据；部分掌握不增加确认，未掌握会按普通练习规则重置当前累计，跳过不记录。

索引叶子的毕业策略按实际绑定的不同真题数设定：最多要求 3 道；不足 3 道时按可用来源数下调。因为目录没有可靠标注原卷题型与变式，系统只使用独立的“历年真题”题型配额，不虚构选择/大题或变式标签。达到不同题目数后还要求有效掌握确认与相应跨天间隔。普通知识点和题库题原有规则不变；任何带来源关联的可考核知识点都可从知识树加入今日学习。普通知识点沿用原有毕业规则，原卷自评作为额外真实题证据；历年索引节点使用自适应毕业门槛且不进入默认推荐。

项目不复制年度原卷 PDF。界面显示题目链接（来源有提供时）、标签来源，以及 `桌面 / 考研知识点 / <科目>/<年份>` 的本地目录提示。数学二部分年份没有稳定的逐题直链，需要在本地 PDF 中按题号核对。

## 导入与验证

数据库先迁移，再运行只更新历年索引及专题聚合节点的定向脚本：

```powershell
alembic upgrade head
python scripts/seed_exam_references.py
```

定向脚本会幂等导入精细考点、专题汇总节点和题号关联，并为新索引节点创建掌握度状态及来源数量适配的毕业策略；它不会重跑普通学习题库、讲解或资料种子，也不会删除已有学习进度、练习记录或题目。关联数据直接从已版本控制的年度 Markdown 索引解析，重复运行不会重复插入；自动维护的索引策略在来源数量变化时更新，手动自定义策略不会覆盖。

专题汇总是便于浏览和练习的宽口径，不是官方考点频率统计。年度题目行和来源标签数量不等于独立题目数；报告专题覆盖时应按“科目 + 年份 + 题号”去重。细粒度标签仍是第三方或人工归纳，尚未逐题独立核验。

覆盖边界和来源可信度见 [收录范围与授权说明](../resources/考研统考资料_数学二_408_2000至2026/收录范围与授权说明.md) 与 [逐题核验状态](../resources/考研统考资料_数学二_408_2000至2026/逐题核验状态.md)。标签是复习索引而非官方命题标注，尚未逐题独立核验；索引关联不表示对题目版权或再分发许可的判断。
