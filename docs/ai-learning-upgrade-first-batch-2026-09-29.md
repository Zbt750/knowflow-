# 学习证据改造：第一批基础修复

本文记录首批落地时的状态；后续已接入提交功能，见 [第二批答题闭环记录](answer-submission-upgrade-2026-09-29.md)。下文“尚未接入”不代表当前版本状态。

改造前已备份：本地 master c841adb，GitHub main b286156。

## 已落地

- 修复检索栈维度不匹配分支遗漏 VectorStoreError 导入的缺陷。
- 修正洛必达法则单选题的歧义选项：原 C 选项也是可直接使用法则的 0/0 商，不能将 A 判为唯一答案。新 C 为需要通分的发散项之差。
- 加入保守数值最终答案判定基础：有限长度十进制、整数和分数的精确比较，不执行用户表达式，不猜测公式、单位或证明。仅明确核验过标准答案时允许判定；空白与不支持的输入返回 unknown。
- 全卷浏览补充可选作答记录，与专注模式共用现有 rawAnswers 与提交链路。保持纸笔优先、小输入区和白色界面；已完成或提交中的作答禁止编辑。

## 明确边界

数值判定模块尚未接入在线判题或掌握度投影。当前界面明确标注“暂不自动判分”，旧自评业务保持不变。不能把最终答案正确当成证明过程正确或知识毕业。

种子题修正只影响种子文件；已有数据库题目尚未同步，未执行重新灌库或更改用户历史。

下一批需要确定并实现答案核验标记、判题配置、提交与判题证据持久化，以及答案查看对辅助作答的标记，再接入新提交接口。复杂表达式、证明、讨论、程序执行与图片识别不在本批支持范围。

## 验证

独立纯逻辑与替身测试 15 条通过：数值格式、安全输入、未核验答案、维度异常类型。
这些测试使用独立 confcutdir，不代表数据库集成测试通过。当前未启动测试数据库，未运行 E2E，也没有发起付费模型调用。
