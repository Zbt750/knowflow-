# 第二批判题核验与内容勘误

## 本批范围

核验种子中的简单单选及单一数值结果，已启用自动核对由 3 道扩为 14 道（8 单选、6 数值）。均为项目现有教学演示题，不宣称是真题或整个数学二/408覆盖。

核验依据：

| 类别 | 检查依据 |
| --- | --- |
| 洛必达已有3题 | 0/0型条件、指数函数在0处导数、因式分解 |
| 等价无穷小单选 | sin x / x→1；tan 2x / x→2；1−cos x 和 ln(1+x²) 均不是与x等价 |
| 对数极限 | ln(1+x)在0处导数为1 |
| 错误替换单选 | ln(1+x)−x 的二阶项为 −x²/2，不是0 |
| 圆的隐函数导数 | −x/y，在(3,4)为−3/4，其他选项不等 |
| 等比级数题 | 非零首项收敛条件为绝对值公比小于1；负公比−1/2和为2a/3；公比1/2求和为2；公比1/3且和1则首项2/3 |
| 行列式题 | 对换两行变号；三阶数乘为k³倍；逆矩阵行列式为原行列式的倒数 |

最终答案核对不评价过程。多结论填空、公式、切线方程、多结果、证明、讨论及程序题仍保留人工对照，不能用参考答案恰好出现数字就启用机器评分。

## 实际错误及修复

曲线 `y²=x³−3x+1` 在 `(0,1)` 处由 `2y·y'=3x²−3` 得斜率 `−3/2`，正确切线 `y=−3x/2+1`。旧答案错误写成 `−3`，已修正种子答案和解析。该题仍不自动评分。

同步脚本只在开发题目的答案、类型、选项、解析与核验种子精确一致时写入配置；已有不同配置或人工修改跳过。切线勘误只接受完整匹配的已知旧版本。不会重写历史作答、旧判题快照或掌握状态；后续阅读使用修正后的解析。
