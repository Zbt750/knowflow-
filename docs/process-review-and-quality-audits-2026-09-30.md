# 文字过程审阅与质量审计

## 本轮实现

- 今日学习专注与全卷模式提供折叠式“检查我的过程”，支持计算过程、证明、概念讨论和算法伪代码。默认不展开，不替代纸上作答。
- 本卷作答小结按实际提交结果分别统计正确、错误、未判定、辅助作答和仅自评，不调用模型生成额外结论。
- POST `/api/practice-items/{item_id}/process-reviews` 按需调用当前模型，GET 同路径 `/latest` 恢复最后一次反馈。
- 审阅不完成题目、不判分、不更新掌握度或毕业状态。之后的答案提交标记为辅助作答，不累计独立确认。
- 保存反馈、输入摘要、调用统计，不保存原始过程文字；反馈通过净化后的 Markdown 渲染。请求失败不落辅助事件，同一请求键重试不重复落库。
- 同时到达的重复请求可能产生重复上游调用，但事件唯一约束保证只写一条记录；前端处理中禁用操作。跨进程调用去重仍需独立持久任务机制。

后续 D-86 已补当前单进程按题目/键的并发保护，见 `process-review-concurrency-2026-09-30.md`；上面“可能重复调用”是本功能首批实现的边界，不代表当前单进程并发行为。跨进程与崩溃后的上游计费仍不保证恰好一次。
- 未查看解析时不把标准解析送入审阅提示词。AI 建议可能有误，不是可靠的数学证明检查器，也不会执行用户代码。
- 图片审阅明确延期；现有 Question 的题型和题干决定入口，原卷引用不能冒充在线题。

## 评测与资产检查

`scripts/audit_multichunk_facts.py` 根据固定事实清单核对实际上下文与回答要点，不替代 RAGAS 或人工事实检查。引用检查只证明对应来源编号在回答某处出现，不证明每个结论都被正确归因。

`scripts/audit_knowledge_assets.py` 只读检查当前版本知识范围、讲解结构、在线题和原卷引用。304 个项目节点有讲解，不等于考试大纲已全覆盖；在线可作答题 22 道、原卷题目引用去重 1184 道，须分开陈述。现有 408 节点缺少完整在线题干，不能据此承诺自动判题覆盖。
