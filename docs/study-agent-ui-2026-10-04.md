# 今日学习入口与答题界面简化（2026-10-04）

本次仅调整学习任务入口和答题交互，复用已有 Agent、确认接口、判题及学习证据服务。没有扩展模型能力、变更题目核验状态或修改数据库结构。

## 当前交互

- “安排学习”仅位于今日学习页，准备页和已有卷都能使用，默认折叠。问答的两种资料范围不再显示该面板；普通问答和找题联动保持原有能力。
- 输入目标与本次分钟数后才执行任务；展开面板或恢复页面不会重新运行模型。先看草案、修改，再明确确认。
- 确认回执触发今日卷只读刷新，不需要再跳转页面。确认响应丢失但服务器已经保存时，读取回执也触发刷新，不重复确认或添加题目。
- 专注模式提供“上一题 / 下一题”，按卷内题型排序后的完整顺序导航，包括已完成题。首尾禁用越界按钮，不循环跳转。
- 上下题不调用提交、自评或跳过接口；未提交的文字与选项在当前页面中保留。提交答案和自行对照记录都停留在当前题，用户主动切换，保留阅读解析的机会。
- 全卷模式无“跳过”按钮，不做某题可以留空；原卷引用题也遵循同一导航边界。
- 两种视图均不再显示做题信心控件或每题尝试历史。新提交不填写 confidence；旧记录不删除。
- “本卷做题记录”与“今日涉及的知识点”合并为同一个默认折叠区域，展开后可以查看结果摘要、错题入口和知识点完成数量。
- 来源、题型、简短结果标记、默认收起的题目信息、可展开/收起的解析，以及开放题的折叠辅助审阅保留。题目未核验时仍不冒充可靠机器判题。
