# I/O 设备分类与接口

## 概念、定义与适用条件

I/O 设备可按传输单位分为字符设备与块设备，按数据方向分输入、输出或双向设备，也可按共享/独占、速度和交互方式分类。设备控制器向 CPU/总线呈现寄存器、状态位、中断/DMA 能力等接口；驱动把 OS 通用请求转换为设备专用命令。分类是为了选择合适的数据组织、缓冲和控制方式。

**例题。** 键盘与磁盘通常分别更接近字符设备还是块设备？分类后对上层接口有什么提示？

**分析与逐步解答。** 键盘按按键事件/字符流提供数据，通常按字符设备模型处理；磁盘可按固定大小块随机读写，通常按块设备模型处理。块设备适合缓存、块号定位和文件系统映射；字符设备常提供顺序流和设备特定控制。具体 OS 可能提供统一的文件接口，但底层语义仍不同。

**易错边界。** 分类不是物理接口电气标准的分类；网络设备等可能使用专门包接口，不能简单硬套字符/块两类。驱动与控制器也不是同一实体。
