# 拓扑排序

## 概念、定义与适用条件

拓扑排序是有向无环图（DAG）的顶点线性序列，使每条有向边的起点都在终点之前。Kahn 算法反复选择入度为 0 的顶点输出并删除其出边；若最后仍有未输出顶点，图中有有向环。多个入度为 0 顶点可选时，拓扑序通常不唯一。

**例题。** 有边 $A\to C,B\to C,C\to D$，写出一个拓扑序，并判断是否唯一。

**分析与逐步解答。** 初始入度为零的是 A、B。先取 A，再取 B，C 的入度降为零；输出 C 后 D 入度为零，最后输出 D，得到 `A,B,C,D`。若第一步先取 B、再取 A，也得到合法序列 `B,A,C,D`，因此不唯一。所有边均从较早顶点指向较晚顶点。

**易错边界。** 有向图有环则不存在拓扑序；无向图不进行通常意义上的拓扑排序。拓扑序只是满足先后约束，不表示最短路或权值最优。

## 阅读总结
