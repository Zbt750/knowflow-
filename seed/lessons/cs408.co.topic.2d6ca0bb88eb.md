# 半导体存储器（SRAM/DRAM/Flash）

## 概念、定义与适用条件

SRAM 用交叉耦合锁存结构保存状态，不需周期刷新，速度快、集成密度较低、成本较高，常用作 Cache。DRAM 以电容电荷保存数据，需要刷新且读出具有破坏性并需恢复，密度高，常用于主存。Flash 是非易失性存储器，可电擦写，擦除粒度通常大于读写粒度；它不等同于 SRAM 或 DRAM。

**例题。** 一台机器用 DRAM 作主存、SRAM 作 Cache。若 DRAM 单元电荷会泄漏，说明为什么需要刷新，以及 Cache 为什么通常不采用同样方式保存。

**分析与逐步解答。** DRAM 的电容电荷随时间衰减，控制器需在规定时间内逐行读出/恢复或刷新，避免位值丢失；刷新占用存储器带宽并影响访问调度。SRAM 由锁存器维持状态，只要供电就不需周期刷新，访问延迟通常更低，适合容量较小、速度要求高的 Cache，但单位容量成本更高。

**易错边界。** “静态/动态”指存储单元保持机制，不等于非易失/易失的简单同义替换；SRAM 和 DRAM 断电后都失去数据。Flash 擦写寿命和擦除块约束也需考虑。
