# Cache 写策略

## 概念、定义与适用条件

写命中时，写直达同时更新 Cache 与下一级存储器，控制简单但产生较多写流量；写回只更新 Cache 行并置脏位，替换脏行时再写回，能减少流量但需维护一致性。写不命中时常见写分配（先调入块再写）与非写分配/写绕过（直接写下一级）。命中策略和不命中策略是两个独立选择维度。

**例题。** 某 Cache 采用写回、写分配。对一次写不命中，随后再次写同一块，说明存储器数据何时更新。

**分析与逐步解答。** 第一次写不命中先把包含目标字的块装入 Cache，再修改 Cache 中对应字并置脏位；此时下一级存储器通常仍保留旧值。第二次写命中继续改 Cache 并保持脏位。该脏行被替换或执行显式写回时，整块才写到下一级。

**易错边界。** 写直达/写回描述命中更新策略，写分配/非写分配描述不命中行为。脏位只在写回策略下用于标记缓存数据尚未同步；写缓冲可改变完成时序但不改变基本定义。

## 阅读总结

解题时先写清机器约定和字段/时序，再逐步计算并核查边界；练习题从该节点关联题库获取，本讲解不重复收录练习题。
