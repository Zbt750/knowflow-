# I/O 接口

## 概念、定义与适用条件

I/O 接口连接处理器/总线与外设，通常包含数据寄存器、状态寄存器、控制寄存器及地址译码和握手逻辑。接口屏蔽设备速度、格式和信号差异，提供寻址、状态查询、控制和数据缓冲。存储器映射 I/O 与独立编址 I/O 的地址空间和访问指令方式可能不同。

**例题。** CPU 写数据寄存器时设备仍忙。一个具有 ready 状态位和数据寄存器的接口，如何避免覆盖未取走的数据？

**分析与逐步解答。** CPU 先读取状态寄存器，只有 ready/可接收状态成立时才写数据寄存器；写入后接口将状态改为忙或清除 ready，设备取走数据后再置 ready。实际协议也可能用握手线或 FIFO 深度表示可接收容量，必须按状态语义操作。

**易错边界。** 接口寄存器不等于外设本体；中断、查询或 DMA 是 CPU 与接口交换数据的方式，不是接口内部状态寄存器的替代品。状态位读清除等副作用需以题设为准。

## 阅读总结

解题时先写清机器约定和字段/时序，再逐步计算并核查边界；练习题从该节点关联题库获取，本讲解不重复收录练习题。
