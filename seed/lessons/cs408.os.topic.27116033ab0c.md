# 页式管理

## 概念、定义与适用条件

分页把逻辑地址空间分成固定大小的页，把物理内存分成同样大小的页框。页号索引页表得到页框号，页内偏移原样保留。若页面大小为 $2^p$ 字节，则地址低 $p$ 位是偏移，其余高位是页号。页表可有多级或由 TLB 加速；分页消除外部碎片，但末页可能有内部碎片。

**例题。** 字节编址、页面大小 1 KiB，逻辑地址 2500，页表显示页 2 在页框 7，求物理地址（地址从 0 编号）。

**分析与逐步解答。** 每页 $1024$ 字节。页号为 $\lfloor2500/1024\rfloor=2$，页内偏移为 $2500-2\times1024=452$。物理地址为 $7\times1024+452=7620$。页内偏移不变，替换的是页号到页框号的映射。

**易错边界。** 页大小必须换成字节并确认地址从 0 还是 1 编号；页表项无效时会引发缺页或保护异常，而不是得到一个任意物理地址。
