# 经典同步问题

## 概念、定义与适用条件

经典问题用于检验同步方案是否满足互斥、进展和有限等待。生产者—消费者要同时约束空槽、已有产品和缓冲区互斥；读者—写者要在并发读与排他写之间取舍公平性；哲学家就餐需避免相邻冲突与循环等待。题目要区分死锁、饥饿和吞吐公平。

**例题。** 容量为 N 的有界缓冲区使用 `empty=N, full=0, mutex=1`。分别给出生产者与消费者的 P/V 次序，并说明为什么不能先 P(mutex) 再等待 empty/full。

**分析与逐步解答。** 生产者执行 `P(empty); P(mutex); 插入; V(mutex); V(full)`；消费者执行 `P(full); P(mutex); 删除; V(mutex); V(empty)`。若生产者先持有 mutex 后因 empty=0 阻塞，消费者即使有产品也无法取得 mutex 删除产品，形成互相等待。因此先等待资源条件，再进入临界区。

**易错边界。** 信号量初值表示资源/事件数量；消费者不能在删除前 V(empty)，生产者也不能在写入前 V(full)。读者优先方案可能使写者饥饿。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
