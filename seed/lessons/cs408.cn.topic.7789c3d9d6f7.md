# 子网划分 / 子网掩码 / CIDR / NAT

## 概念、定义与适用条件

CIDR 用 `/p` 表示前 p 位网络前缀，剩余位为地址块内主机位。传统可分配主机数常为 $2^h-2$，但点到点 `/31`、单主机 `/32` 等有特殊语义。子网计算用地址与掩码按位与得到网络地址；广播地址把主机位全置 1。NAT 在边界设备改写地址/端口以映射内外流，破坏端到端地址透明性并需维护状态。

**例题。** 地址 `192.168.10.77/26` 的网络地址、广播地址和传统可用主机范围是什么？

**分析与逐步解答。** `/26` 掩码末字节为 192，子网块大小为 $256-192=64$。末字节 77 落在 64–127 块，网络地址为 `192.168.10.64`，广播地址为 `192.168.10.127`。传统可用主机为 `.65` 至 `.126`，共 $2^6-2=62$ 个。题目若使用特殊点到点规则则另论。

**易错边界。** CIDR 聚合要求前缀对齐且路由器按最长前缀匹配。NAT 不是子网划分；公网私网地址规划与 NAT 转换是不同概念。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
