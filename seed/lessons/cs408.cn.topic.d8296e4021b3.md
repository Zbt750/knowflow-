# FTP 协议

## 概念、定义与适用条件

FTP 使用控制连接交换命令/响应，并另建数据连接传送文件或目录列表。经典 FTP 控制连接常用 TCP 21 端口；主动/被动模式的区别在数据连接由哪端发起，受到 NAT 和防火墙影响。FTP 可进行登录、目录操作和文件传输；明文 FTP 不加密凭据，安全场景通常改用加密替代方案。

**例题。** 被动模式下客户端位于 NAT 后，服务器在控制连接中告知数据端口。谁发起数据 TCP 连接，为什么更利于客户端穿越防火墙？

**分析与逐步解答。** 被动模式由客户端向服务器通告的数据端口主动建立数据连接；许多防火墙允许内网客户端发起的出站连接，而阻止外部主动连入，因此相较传统主动模式更容易穿越客户端 NAT/防火墙。服务器仍需开放被动端口范围。

**易错边界。** 控制连接与数据连接分开；主动/被动描述 TCP 建连方向，不代表文件数据方向本身。FTPS 与 SFTP 是不同机制/协议。
