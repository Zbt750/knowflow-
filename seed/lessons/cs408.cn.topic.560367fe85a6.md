# VLAN

## 概念、定义与适用条件

VLAN 在二层交换网络中把端口划分为逻辑广播域，减少广播范围并提供隔离。接入端口通常承载一个未标记 VLAN；Trunk 链路可携带多个 VLAN，常使用 IEEE 802.1Q 标签标记 VLAN ID。跨 VLAN 通信需三层路由，不会因为交换机能转发帧就自动互通。

**例题。** 一台交换机有 VLAN 10 与 VLAN 20，各自接入主机 A、B；二者 IP 位于不同网段。仅增加一个 Trunk 端口能否使 A、B 通信？

**分析与逐步解答。** Trunk 只允许多个 VLAN 的二层帧在链路上传输并保留 VLAN 标识，不完成三层转发。A、B 要跨子网通信还需路由器或三层交换机配置对应 VLAN 接口/网关及路由策略。没有路由功能时两个 VLAN 仍是不同广播域。

**易错边界。** Trunk 不是“把 VLAN 合并”；Native VLAN/标签处理依设备配置。802.1Q VLAN ID 有保留值，具体可用范围按标准和题目口径。
