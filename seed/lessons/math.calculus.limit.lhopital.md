# 洛必达法则

洛必达法则的任务，是把某些难以直接代入的分式极限，转成分子、分母分别求导后的极限。它不是“见到分式就求导”：先判断类型和条件，再决定能否使用。

## 一、先认出未定式

直接代入若得到 $0/0$ 或 $\infty/\infty$，仅说明原式**还不能由代入确定**，并不说明答案是零、一或无穷。先尝试约分、等价无穷小、恒等变形；需要时再用洛必达法则。

设 $f$、$g$ 在所讨论点附近的去心区间内可导，$g'(x)\ne0$，且 $f(x)/g(x)$ 呈 $0/0$ 或 $\infty/\infty$ 型。如果 $\lim f'(x)/g'(x)=L$ 存在（也允许趋向无穷），就可以得到 $\lim f(x)/g(x)=L$。单侧极限要在相应的单侧邻域内检查这些条件。

特别记住：求的是 **$f'(x)/g'(x)$**，不是对整个商再求导。

## 二、做题步骤

1. 写出 $x$ 的趋向和直接代入后的类型。
2. 检查分子、分母在附近是否可导，以及分母的导数是否为零。
3. 分别对分子和分母求导，再求新分式的极限。
4. 若新分式仍是允许的未定式，可以再次使用；一旦能直接求值就停止。

## 三、例题：需要使用两次

求 $\displaystyle\lim_{x\to0}\frac{e^x-1-x}{x^2}$。

**思路。** 代入得到 $0/0$。分子和分母在零附近可导，分母导数 $2x$ 在去心邻域内不为零，因此可以分别求导：

$$\lim_{x\to0}\frac{e^x-1-x}{x^2}
=\lim_{x\to0}\frac{e^x-1}{2x}.$$

新分式仍是 $0/0$ 型，条件仍满足，再做一次：

$$\lim_{x\to0}\frac{e^x-1}{2x}
=\lim_{x\to0}\frac{e^x}{2}
=\frac12.$$

**结论。** 极限为 $\frac12$。第二次求导后已经可以直接代入，不必再求导。

## 四、变式：先变形，再使用法则

求 $\displaystyle\lim_{x\to0^+}x\ln x$。这里是 $0\cdot(-\infty)$，不是洛必达法则直接处理的分式类型。先改写：

$$x\ln x=\frac{\ln x}{1/x}.$$

此时是 $(-\infty)/\infty$ 型。在 $x>0$ 上分子、分母可导，分母导数 $-1/x^2$ 不为零，于是

$$\lim_{x\to0^+}\frac{\ln x}{1/x}
=\lim_{x\to0^+}\frac{1/x}{-1/x^2}
=\lim_{x\to0^+}(-x)=0.$$

这一题的关键并非多求导，而是**先把不适用的形式改成适用的分式**。

## 五、容易出错的地方

- 把 $0\cdot\infty$、$\infty-\infty$ 或 $1^\infty$ 直接套入法则；它们要先变形。
- 只看原式是 $0/0$，不检查新分式的类型和分母导数。
- 以为导数之比的极限不存在就能断言原极限不存在。法则此时不能给结论，应换方法。
- 把求导写成 $(f/g)'$；那与 $f'/g'$ 是两回事。

**自查。** 每次下笔前问自己：“现在确实是允许的未定式吗？这一次求导后能否直接求值？”读懂后可在本页底部进入对应题库练习。

## 本节点概念摘要

极限研究变量趋近某点或无穷远时函数值的变化趋势；连续性则把极限与函数值接起来。等价无穷小只能在保持乘除结构时替换，加减抵消时要保留高阶项。
