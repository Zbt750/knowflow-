# 差错控制（链路层）

## 概念、定义与适用条件

差错检测通过冗余位发现传输错误，差错纠正可由 FEC 直接修复或由 ARQ 请求重传。奇偶校验简单但检测能力有限；CRC 将比特串视为 GF(2) 多项式并除以生成多项式，余数作为校验序列；接收端余数非零可检测许多突发错误，但 CRC 不能纠正错误。

**例题。** 数据多项式为 `1101`，生成多项式比特串为 `1011`（阶数 3）。CRC 发送端应附加多少个 0、得到的校验余数位数是多少？

**分析与逐步解答。** 生成多项式阶数为 3，因此在数据后补 3 个 0，形成 `1101000`。按模 2 长除法逐次对齐并异或：`1101000 XOR 1011000 = 0110000`；`0110000 XOR 0101100 = 0011100`；`0011100 XOR 0010110 = 0001010`；`0001010 XOR 0001011 = 0000001`。末 3 位余数为 `001`，发送码字为 `1101001`。接收端对完整码字除以同一生成多项式，余数为 0 表示未检出错误。

**易错边界。** 模 2 减法是异或、无借位；生成多项式最高位/最低位应按协议顺序对齐。检错能力取决于生成多项式与错误模式。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
