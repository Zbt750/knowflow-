# 行列式的性质

行列式给一个方阵对应一个数。做题时不必总按定义展开：行变换、乘积公式和非零判据通常更快，也更能说明矩阵是否可逆。

## 一、从二阶行列式理解

对于 $A=\begin{pmatrix}a&b\\c&d\end{pmatrix}$，有 $\det A=ad-bc$。它可能为正、负或零。$\det A=0$ 表示方阵不可逆；$\det A\ne0$ 才能求逆。

行列式只对方阵定义。把一个矩阵的某一行乘 $k$ 与把**整个** $n$ 阶矩阵乘 $k$，结果不同：前者行列式乘 $k$，后者乘 $k^n$。

## 二、最常用的性质

| 操作或关系 | 行列式如何变化 |
| --- | --- |
| 交换两行（或两列） | 变号 |
| 某一行乘 $k$ | 乘 $k$ |
| 一行加上另一行的 $k$ 倍 | 不变 |
| 两行相同或成比例 | 等于零 |
| 同阶方阵相乘 | $\det(AB)=\det A\det B$ |
| $n$ 阶方阵整体乘 $k$ | $\det(kA)=k^n\det A$ |

行变换的三条规则对列也成立；但一次变换到底作用于行还是列，要在计算中保持清楚。

## 三、例题：行变换

设 $A=\begin{pmatrix}1&2\\3&4\end{pmatrix}$。直接计算 $\det A=1\cdot4-2\cdot3=-2$。

交换两行后得到 $A_1=\begin{pmatrix}3&4\\1&2\end{pmatrix}$，因此 $\det A_1=2$。若把原矩阵第一行乘 $3$ 得到 $A_2$，则 $\det A_2=3\det A=-6$。两个操作不要混在一起计算。

## 四、变式：整体数乘与矩阵乘积

仍用上面的二阶矩阵 $A$。把整个矩阵乘 $3$，相当于两行都乘 $3$，因此

$$\det(3A)=3^2\det A=9(-2)=-18.$$

若 $B=\begin{pmatrix}2&0\\0&1\end{pmatrix}$，则 $\det B=2$，无需先算 $AB$ 的所有元素，就能得到 $\det(AB)=(-2)\cdot2=-4$。

## 五、容易出错的地方

- 把“某一行乘 $k$”错用成“整个矩阵乘 $k$”。
- 交换两行后漏掉负号。
- 把 $\det(A+B)$ 写成 $\det A+\det B$；一般没有这样的加法公式。
- 行列式为零时还去套逆矩阵公式。

**自查。** 我这一步改变的是一行、一列，还是整个矩阵？这个区别决定乘一次 $k$ 还是乘 $k^n$。

## 本节点概念摘要

行列式是方阵对应的标量，反映可逆性与体积缩放。行变换对行列式的影响需区分交换、倍乘和倍加。
