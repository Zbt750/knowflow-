# I/O 软件层次结构

## 概念、定义与适用条件

典型 I/O 软件层次自上而下包括用户进程/库接口、设备无关 I/O 软件、设备驱动程序和中断处理程序，底层为硬件控制器与设备。设备无关层统一命名、权限、缓冲和错误处理；驱动把通用请求转换成特定控制器操作；中断处理快速确认事件并唤醒等待者或推进状态。

**例题。** 应用请求从磁盘文件读取数据。请按层次说明一个典型请求的处理链。

**分析与逐步解答。** 应用调用 read；内核通用文件/I/O 层校验描述符并定位文件块，必要时交给块设备层；磁盘驱动配置控制器命令和 DMA 缓冲；设备完成后控制器发中断，中断处理程序确认状态并唤醒等待进程；数据经页缓存/内核缓冲返回用户空间。具体路径会因缓存命中、异步 I/O 或直接 I/O 改变。

**易错边界。** 中断处理程序属于内核路径，不是设备驱动的唯一组成方式。用户库可能做缓冲，使一次应用读并不立即对应一次设备访问。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
