# 计算机网络

> 408 · 上级节点：408 计算机学科专业基础  
> 本页按本项目知识树的课程结构原创整理，实际考试边界以当年正式考试说明为准。

## 一、概念讲解

这是“408 计算机学科专业基础”下的组织节点，包含：网络分层与参考模型、网络性能指标、网络层功能、路由算法、路由协议（RIP/OSPF/BGP）、拥塞控制（网络层视角）、ARP / DHCP / ICMP、IPv4 分组与地址、子网划分 / 子网掩码 / CIDR / NAT、路由器组成与功能、TCP 流量控制、DNS 系统、随机访问 MAC、通信基础、选择重传（SR）、无线局域网、TCP 连接管理、TCP 可靠传输、以太网 / IEEE802.3、流量控制与可靠传输、后退 N 帧（GBN）、电子邮件、编码与调制、数据链路层功能与组帧、以太网交换机、奈奎斯特与香农定理、信道划分 MAC、TCP 拥塞控制、传输层功能、UDP 协议、WWW 与 HTTP、FTP 协议、停止-等待协议、传输介质、网络应用模型、差错控制（链路层）、IPv6、VLAN、网络概念组成与功能、专题汇总：应用层协议、专题汇总：网络层与 IP、专题汇总：传输层与 TCP/UDP、专题汇总：数据链路与局域网、专题汇总：物理层与通信基础。

应用层协议定义应用进程交换消息的格式和语义。DNS 解析名称，HTTP 描述请求/响应；性能题还需区分带宽、吞吐和时延组成。

**读题时要抓住的核心：**先确认题目考查的对象和目标，再把节点名称对应到定义、成立条件、操作步骤或判别标准；不要只凭关键词套公式。涉及子主题时，回到上级“408 计算机学科专业基础”检查知识边界。

## 二、解题方法

协议题按客户机/服务器角色、请求顺序和缓存状态追踪；时延题分解发送、传播、处理和排队部分。

**自查顺序：**①对象/变量和边界是否明确；②使用的定理或算法是否满足条件；③计算/状态更新是否逐步可复核；④结果是否代回题意检查。

## 三、例题讲解（原创）

浏览器访问新域名时，先查询本地/递归 DNS 缓存；未命中则解析获得 IP，随后建立传输连接并发送 HTTP 请求。
