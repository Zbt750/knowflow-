# 中序遍历

## 概念、定义与适用条件

中序遍历按“左子树—根—右子树”访问。对二叉搜索树，因左子树键小于根、右子树键大于根，中序输出为递增序列。迭代实现可沿左链不断入栈，弹出访问后转向右子树。中序遍历只对二叉树有明确的左右顺序。

**例题。** 对根 A、左孩子 B（B 的左右孩子 D、E）、右孩子 C 做中序遍历。

**分析与逐步解答。** 先遍历 B 的左子树 D，再访问 B，再遍历 B 的右子树 E，左子树结果为 `DBE`；然后访问根 A；最后访问右子树 C。完整序列为 `DBEAC`。按递归调用检查时，每个结点都在其左子树完成后、右子树开始前输出。

**易错边界。** 不要与前序“根先”或后序“根后”混淆。一般二叉树中序结果不必有序，只有满足 BST 次序时才有此性质。
