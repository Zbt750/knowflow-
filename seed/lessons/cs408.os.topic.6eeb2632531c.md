# 操作系统概念与发展

## 概念、定义与适用条件

操作系统是管理资源并向程序提供抽象的系统软件。批处理减少人工干预；多道程序提高 CPU 与 I/O 重叠利用率；分时系统通过快速切换提供交互响应；实时系统关注时限与可预测性；分布式、移动和虚拟化系统扩展了资源管理范围。分类取决于主要设计目标，现实系统常兼具多种特征。

**例题。** 单道批处理系统中，程序等待慢速 I/O 时 CPU 常空闲；多道程序系统为何可能提高 CPU 利用率？

**分析与逐步解答。** 多道程序把多个作业驻留内存。一个作业因 I/O 阻塞时，调度器可运行另一个已就绪作业，使 CPU 与设备工作重叠，减少 CPU 空闲时间。若所有作业同时等待同一瓶颈设备，或内存不足以容纳合适作业数，利用率提升并无保证。

**易错边界。** 多道程序强调资源重叠利用，不自动等同于并行硬件；分时强调交互响应与时间片。实时系统核心是时限约束，不简单以“速度快”定义。
