# 传输层功能

## 概念、定义与适用条件

传输层在端系统进程之间提供通信服务，利用端口号复用/分用应用数据，可能提供可靠字节流、流量控制、拥塞控制或无连接数据报。TCP 面向连接且可靠；UDP 无连接、报文边界保留、尽力交付。应用协议可选择传输服务，再在应用层补充自身需要的可靠性或安全机制。

**例题。** 同一主机同时运行 Web 服务和 DNS 服务，收到两个目的 IP 相同但目的端口不同的传输层报文，端口号起什么作用？

**分析与逐步解答。** IP 地址把分组送到主机；传输层目的端口帮助主机把负载交给相应套接字/应用进程，实现进程级分用。TCP 与 UDP 的端口空间在协议上分别处理，应用还可能结合源地址、源端口和连接状态区分会话。

**易错边界。** 端口号不是主机 IP；“传输层可靠”一般指 TCP 服务，不是所有传输协议都提供可靠性。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
