# 上下文切换

## 概念、定义与适用条件

上下文切换保存当前执行流的处理器状态并恢复另一个执行流状态，如 PC、通用寄存器、栈指针、状态字和地址空间相关信息。它本身不执行用户工作，带来直接保存/恢复成本以及缓存、TLB等微架构状态变化的间接成本。进程切换通常还可能涉及地址空间切换，线程切换是否切换地址空间取决于线程是否同属一个进程。

**例题。** P1、P2 是同一进程的两个内核线程，调度器将 CPU 从 P1 切到 P2。哪些状态必须切换，是否一定切换页表？

**分析与逐步解答。** 需要保存 P1 的 PC、寄存器、栈指针等执行上下文，并恢复 P2 对应状态。两线程共享同一进程地址空间，因此一般无需切换到不同页表；但调度器仍需更新线程状态和内核栈。实际硬件上下文组成由 ABI/体系结构决定。

**易错边界。** 模式切换不一定等于进程上下文切换；系统调用可进入内核后仍返回同一进程。切换成本不能只数寄存器保存指令。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
