# I/O 控制方式

## 概念、定义与适用条件

程序查询由 CPU 忙等状态并搬运数据；中断方式让设备就绪后通知 CPU，CPU 仍执行服务程序搬运；DMA 由 DMA 控制器在设备与内存间批量搬运，CPU 配置后可继续执行并在完成时处理中断。三者在 CPU 参与频度、数据粒度、硬件复杂度和吞吐上有不同取舍。

**例题。** 设备要向主存连续写 1 MiB 数据，比较查询、中断和 DMA 哪种方式更适合减少 CPU 逐字搬运开销。

**分析与逐步解答。** 查询方式需 CPU 反复检查并搬每份数据，忙等明显；中断可避免持续轮询，但若每字/小块中断，CPU 仍频繁运行服务程序搬运；DMA 可由控制器按地址和长度在设备与主存间成块传送，CPU 只需配置和处理完成/错误通知，因此在大块连续传输时通常更合适。具体仍受设备、总线和 DMA 成本影响。

**易错边界。** 中断和 DMA 经常组合使用：DMA 完成后可以中断 CPU。DMA 不代表完全没有 CPU 参与，也会占用总线带宽。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
