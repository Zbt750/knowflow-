# 段式管理

## 概念、定义与适用条件

分段按逻辑模块划分地址空间，如代码段、数据段、栈段。逻辑地址由段号 $s$ 和段内偏移 $d$ 构成；段表项给出段基址与段长/界限，先检查 $d<limit[s]$，再计算物理地址 $base[s]+d$。分段便于保护和共享不同逻辑模块，但段长可变会产生外部碎片。

**例题。** 段表中段 2 的基址为 5000、段长为 800。逻辑地址 $(2,120)$ 和 $(2,900)$ 如何处理？

**分析与逐步解答。** 偏移 120 小于段长 800，物理地址为 $5000+120=5120$。偏移 900 不满足界限，产生地址越界异常，不能映射到 5900。这里假设偏移从 0 开始且段长为合法偏移数。

**易错边界。** 段号选择表项，段内偏移需单独检查；分段与分页的内部/外部碎片特征不同。段页式系统会先分段再分页，地址字段也更多。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
