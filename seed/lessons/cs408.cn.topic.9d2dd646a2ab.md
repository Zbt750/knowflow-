# 网络分层与参考模型

## 概念、定义与适用条件

分层把通信功能划分为相对独立的协议层，同层对等实体按协议交互，相邻层通过服务接口传递数据。发送端数据逐层封装首部/尾部，接收端逆向解封装。OSI 七层为物理、数据链路、网络、传输、会话、表示、应用；常见 TCP/IP 教学模型合并部分上层，层数口径需按题目指定。分层提升模块化，但实际协议可能跨层协作。

**例题。** 应用数据经 TCP、IPv4、以太网发送。依次写出线上数据的封装关系，并指出路由器转发时通常变化的字段。

**分析与逐步解答。** 应用数据加 TCP 首部形成 TCP 段；再加 IPv4 首部成为 IP 分组；再加以太网首部与帧尾成为以太网帧。路由器剥去入链路帧头尾，按 IP 转发并通常递减 TTL、更新首部校验和，再封装为下一跳链路帧。端到端 TCP 首部与应用数据通常保持不变（NAT 等中间设备可能改写字段）。

**易错边界。** 分层模型是抽象，不等于每个设备都实现全部层。交换机、路由器处理的层次不同；封装层次和数据单元名称要按课程约定。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
