# 平衡二叉树（AVL）

## 概念、定义与适用条件

AVL 树是满足二叉搜索树次序且每个结点左右子树高度差至多为 1 的二叉树。插入或删除后，沿受影响路径自底向上更新平衡因子；首次失衡结点按失衡方向采用 LL、RR、LR 或 RL 旋转。旋转要保持中序键值次序，同时重新连接子树并更新高度。

**例题。** 依次插入 3、2、1，说明 AVL 调整过程。

**分析与逐步解答。** 插入 3 后它为根；插入 2 后成为 3 的左孩子；插入 1 后成为 2 的左孩子。结点 3 左子树比右子树高 2，是 LL 型失衡。对 3 做一次右旋，2 成为根，1 为其左孩子，3 为其右孩子。旋转前后中序序列都为 `1,2,3`，二叉搜索树性质保持，树高从 3 降为 2。

**易错边界。** 插入后的调整只沿搜索路径判断；双旋应拆成相邻两次单旋。AVL 树不是完全二叉树，数组孩子下标公式一般不适用。
