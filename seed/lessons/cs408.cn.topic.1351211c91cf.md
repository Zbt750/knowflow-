# 无线局域网

## 概念、定义与适用条件

IEEE 802.11 WLAN 通过接入点或自组织方式提供无线链路。共享无线介质有隐藏终端、暴露终端和衰落问题；Wi‑Fi 通常采用 CSMA/CA，发送端侦听、随机退避，成功接收后由接收端 ACK。RTS/CTS 可预约信道，减少隐藏终端造成的部分碰撞，但会有控制开销。

**例题。** A 与 C 都能到达接入点 B，但 A 与 C 彼此听不到。A 向 B 发送时，C 也发送，说明隐藏终端问题及 RTS/CTS 的作用。

**分析与逐步解答。** A、C 各自侦听不到对方，可能同时认为信道空闲，二者信号在 B 冲突。A 先发 RTS，B 回复 CTS，C 若听到 CTS 则在预约时间内保持静默，给 A 发送数据的机会。RTS/CTS 不能解决所有无线干扰，也可能自身碰撞。

**易错边界。** 无线站点一般不能像传统有线以太网那样边发边检测碰撞。Wi‑Fi ACK 由接收端确认，链路层重传不等同于 TCP 重传。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
