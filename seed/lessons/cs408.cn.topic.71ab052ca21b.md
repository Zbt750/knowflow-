# ARP / DHCP / ICMP

## 概念、定义与适用条件

ARP 在同一链路内把 IPv4 地址解析为链路层地址；DHCP 为主机动态配置 IP、掩码、网关和 DNS 等参数；ICMP 传送差错与诊断信息，如目的不可达、超时和 Echo 请求/应答。ARP 广播作用域受二层广播域限制，跨网段访问时主机通常解析默认网关 MAC，而不是远端主机 MAC。

**例题。** 主机 A 要向不同子网的 B 发送 IP 分组，A 已知默认网关 IP 但不知道其 MAC。它通常发 ARP 查询谁的 IP？

**分析与逐步解答。** A 判断目的 IP 不在本地子网，选择默认网关作为下一跳。它在本地广播域中 ARP 查询网关接口的 IP 地址，获得网关 MAC，再把以 B 为目的 IP 的分组封装到目的 MAC 为网关的帧中。路由器下一跳再进行新的链路层封装。

**易错边界。** ARP 不跨路由器解析远端主机；DHCP 与 DNS 职责不同。ICMP 报文通常封装在 IP 中，不提供应用层可靠传输。
