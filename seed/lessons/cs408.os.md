# 操作系统

## 本章导读与学习路径

操作系统负责管理处理器、内存、文件和 I/O 设备，并为程序提供受控接口。读题时先确认讨论对象是进程还是线程、逻辑地址还是物理地址、互斥还是同步、页表转换还是缺页处理；随后明确题设中的调度策略、资源数量、地址单位、页面访问串或文件分配方式，再逐步推进状态。

建议从系统调用和结构入门，学习进程线程、同步互斥、调度与死锁，再进入内存管理和虚拟内存，最后学习文件系统、I/O 与磁盘。图表题用状态图、时间轴、资源分配图或地址字段分解来表达中间过程。节点是本项目当前知识树的学习组织，不是官方考纲完整性声明；名称明确标为“待核对”的条目不应被误读成已经确认的考点。

**贯通例题。** 两个进程 P1、P2 共享一个互斥信号量 `mutex=1`。P1 执行 `P(mutex)` 后进入临界区，随后执行 `V(mutex)`；说明 P2 的一次 `P(mutex)` 在 P1 释放前后可能发生什么。

**分析与逐步解答。** P1 的 P 操作原子地把可用值从 1 减为 0 并进入临界区。此时 P2 执行 P 会因资源不可用而阻塞，不能同时进入临界区。P1 执行 V 后，系统使一个等待者获得许可（具体唤醒次序依实现/调度），P2 随后可进入。关键保证来自 P/V 操作的原子性和信号量初值为 1，而不是进程恰好按某个固定时刻运行。
