# 顺序栈

## 概念、定义与适用条件

顺序栈用数组保存元素并以栈顶指针记录当前位置。压栈先检查满，再写入并更新栈顶；弹栈先检查空，再取值并更新栈顶。教材实现对 `top` 初值有两种约定：指向最后元素（空栈为 -1）或指向下一空位（空栈为 0），所有操作必须配套一致。

**例题。** 采用 `top=-1` 表示空栈，依次执行 push(A)、push(B)、pop()、push(C)，写出栈内容与 top。

**分析与逐步解答。** 初始 `top=-1`。压入 A 后 `top=0`，再压入 B 后 `top=1`，栈为 `[A,B]`；弹出得到 B，`top=0`；压入 C 后覆盖原第二格，`top=1`，栈为 `[A,C]`。每次 push/pop 只需常数次访问，时间 $O(1)$。

**易错边界。** top 语义不同，空栈和满栈判断条件也不同。固定容量数组溢出时不能越界写入；弹空栈属于下溢。
