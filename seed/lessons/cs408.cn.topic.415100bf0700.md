# WWW 与 HTTP

## 概念、定义与适用条件

WWW 由资源标识（URL/URI）、浏览器/服务器和 HTTP 等协议组成。HTTP 请求/响应包含方法、目标、首部和消息体；HTTP/1.1 常支持持久连接，HTTP/2 多路复用在单连接上并发流，HTTP/3 基于 QUIC。协议无状态指服务器不必自动记住跨请求会话，Cookie/令牌等可维护应用状态。缓存按 Cache-Control、验证器等规则复用响应。

**例题。** 浏览器重复请求同一资源，服务器返回 ETag。客户端下次带 `If-None-Match`，资源未改变时服务器可怎样响应？

**分析与逐步解答。** 若当前表示的 ETag 与客户端提交的验证器匹配，服务器可返回 `304 Not Modified`，不重复发送完整实体；浏览器继续使用缓存内容。若资源已变化，则返回新的表示和验证器。缓存是否允许使用还受缓存指令与权限控制影响。

**易错边界。** HTTP 状态码与 TCP ACK 不同。HTTPS 是 HTTP 与 TLS 等安全机制组合，不是另一种应用层资源命名方式。
