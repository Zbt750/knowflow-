# 虚拟内存（OS 视角）

## 概念、定义与适用条件

虚拟内存使进程拥有独立、可保护并可按需装入的地址空间。页表记录虚拟页到物理页框映射及有效、权限、访问/脏等状态；TLB 缓存转换。访问未驻留页会触发缺页异常，内核验证地址合法性、选择/回收页框、从外存读入页面、更新页表并重启故障指令。缺页处理是软硬件协作，不是 TLB 未命中本身。

**例题。** 进程访问页表项有效但驻留位为 0 的虚拟页，描述一次按需分页缺页的大致处理步骤。

**分析与逐步解答。** MMU 检测访问页不在内存，产生缺页异常并保存可恢复状态；内核确认地址属于进程合法区域和权限允许；分配空闲页框，或选择牺牲页（脏页先写回）；把目标页读入页框并更新页表/TLB；恢复进程并重试导致缺页的指令。若地址非法则终止或报告错误，不应继续装页。

**易错边界。** 页面置换仅在无空闲框时需要；缺页代价通常远高于普通内存访问。合法但未驻留与非法地址要区分。
