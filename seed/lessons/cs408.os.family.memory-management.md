# 专题汇总：操作系统内存管理

> 408 · 上级节点：操作系统  
> 本专题由项目按年度来源标签归并，便于跨年浏览；不是官方命题分类。

## 一、概念讲解

这是按历年真题索引整理的考点条目，归属“操作系统”，索引主题为**专题汇总：操作系统内存管理**。下文提供该主题的概念框架与原创例题；索引标签不代表官方大纲的唯一分类。

操作系统内存管理从逻辑地址映射到物理内存。分页按页/页框管理；页面置换在缺页且无空闲页框时选择淘汰对象。

**读题时要抓住的核心：**先确认题目考查的对象和目标，再把节点名称对应到定义、成立条件、操作步骤或判别标准；不要只凭关键词套公式。涉及子主题时，回到上级“操作系统”检查知识边界。

## 二、解题方法

地址题拆页号与页内偏移；置换题每次访问都更新算法状态。FIFO 看进入时间，LRU 看最近使用时间。

**自查顺序：**①对象/变量和边界是否明确；②使用的定理或算法是否满足条件；③计算/状态更新是否逐步可复核；④结果是否代回题意检查。

## 三、例题讲解（原创）

3 个空页框按 FIFO 访问 1,2,3,1,4。访问 4 时页 1 最早装入，故被淘汰；命中页 1 不改变 FIFO 顺序。
