# CISC 与 RISC

## 概念、定义与适用条件

CISC 与 RISC 是指令系统设计风格的概括，而非绝对的速度分类。传统 CISC 倾向较丰富、长度可变、寻址形式多的指令；传统 RISC 倾向较规整、易译码、寄存器-寄存器运算并由 load/store 访问内存。现代处理器常将复杂指令译为内部微操作，因此现实实现可能跨越这些传统特征。

**例题。** 一条指令同时从内存取数、加到寄存器并写回内存；另一套 ISA 要用 load、add、store 三条指令实现。能否仅据此断定前者更快？

**分析与逐步解答。** 不能。第一种编码指令较少，但内部可能拆为多个微操作，时钟周期、流水能力和缓存行为也影响耗时；第二种指令数较多，却可能译码执行更简单并更易并行。应比较真实工作负载上的 $IC\times CPI\times T_{clk}$ 或实测时间。

**易错边界。** RISC 不意味着“指令总数少”，CISC 也不必然“每条都慢”。现代 ISA、微架构与实现技术交织，考试题中的特征应按明确定义回答。

## 阅读总结

解题时先写清机器约定和字段/时序，再逐步计算并核查边界；练习题从该节点关联题库获取，本讲解不重复收录练习题。
