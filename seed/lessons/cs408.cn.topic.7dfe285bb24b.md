# 网络层功能

## 概念、定义与适用条件

网络层把分组从源主机跨多个链路送往目的主机，核心包括逻辑编址、路由选择和分组转发；还可能提供差错报告、分片或服务质量机制。路由是计算路径/转发表，转发是按当前表把分组从输入接口送到输出接口。IP 通常采用尽力而为的无连接数据报服务，端到端可靠性主要由更高层协议提供。

**例题。** 主机 H1 到 H2 要经过两台路由器。说明链路层地址与网络层地址在每一跳中的作用。

**分析与逐步解答。** IP 源/目的地址通常标识端到端通信主机，路由器依据目的 IP 查表选择下一跳；每段链路上，当前发送者把帧目的 MAC 设为下一跳接口地址，接收路由器去帧后再重新封装下一链路帧。每跳 MAC 会改变，端到端 IP 地址一般保持不变（排除 NAT 等改写）。

**易错边界。** 路由器逐跳转发，不是把原以太网帧不变穿越所有链路。网络层不等同于互联网本身，具体控制协议需按题设。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
