# 内存管理基础

## 概念、定义与适用条件

内存管理为进程提供地址空间并管理物理内存，包括地址绑定/重定位、保护、共享、分配、回收和虚拟化。逻辑/虚拟地址由程序产生，物理地址对应主存位置；MMU 按基址界限、分页或分段等机制转换和检查权限。编译/装载时绑定、执行时动态绑定对程序重定位能力不同。

**例题。** 基址寄存器为 4000，界限寄存器为 1000（表示进程可访问偏移 0 到 999）。逻辑地址 700 和 1200 分别怎样处理？

**分析与逐步解答。** 700 小于界限 1000，转换为物理地址 $4000+700=4700$。1200 不满足偏移小于界限，应触发保护异常，不能简单相加得到 5200。检查界限在加基址前完成，地址单位由题目决定。

**易错边界。** 基址/界限方案与分页的页表转换是不同机制。界限可能定义为长度或上界，严格小于还是小于等于要看题设。
