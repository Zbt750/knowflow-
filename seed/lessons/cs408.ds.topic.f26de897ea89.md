# 邻接矩阵

## 概念、定义与适用条件

邻接矩阵用 $V\times V$ 矩阵表示图。无向图的矩阵对称；简单图中 $a_{ij}=1$ 表示有边，带权图可存权值并用特殊值表示无边。矩阵空间为 $O(V^2)$，判断两顶点是否相邻为 $O(1)$，遍历一个顶点的所有邻居需扫描整行 $O(V)$，适合稠密图或频繁判边。

**例题。** 无向图顶点按 A、B、C 排列，边为 AB、AC，写邻接矩阵并给出各顶点度数。

**分析与逐步解答。** 主对角线为 0，AB 与 BA、AC 与 CA 为 1，其余为 0，矩阵是 $\begin{pmatrix}0&1&1\\1&0&0\\1&0&0\end{pmatrix}$。逐行求和得到度数分别为 2、1、1，总和 4 等于 $2|E|$。

**易错边界。** 有向图矩阵通常不对称；带权无边标记需避免与合法权值冲突。稀疏图使用矩阵会浪费大量空间。
