# 管程与条件变量

## 概念、定义与适用条件

管程把共享数据、互斥访问过程和条件同步封装为模块；同一时刻通常只允许一个线程在管程内执行。条件变量用于等待某谓词成立，`wait` 通常原子地释放管程锁并阻塞，唤醒后重新竞争锁。条件必须用循环检查（`while`），因为可能发生虚假唤醒，或其他线程先改变条件。

**例题。** 有界缓冲区的消费者在 `count==0` 时等待。写出安全的伪代码结构并说明为什么醒来后还要重查。

**分析与逐步解答。** 在持有管程互斥锁时执行 `while count==0: notEmpty.wait()`；条件满足后取出一个元素并更新 count，若有生产者等待则通知 notFull。wait 原子释放锁，使生产者可进入并填充缓冲；醒来后重新获取锁，但可能另一消费者已经取走元素，故不能用单次 if 假设条件仍真。

**易错边界。** 条件变量通知不是资源计数；信号是否记忆取决于同步原语语义。Hoare 与 Mesa 管程对唤醒后控制权语义不同，考试按题设模型回答。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
