# 虚拟机

## 概念、定义与适用条件

虚拟机把一套虚拟硬件接口呈现给来宾操作系统，虚拟机监控器（VMM/hypervisor）负责资源复用、隔离和敏感操作控制。Type-1 通常直接运行在硬件之上；Type-2 运行在宿主操作系统之上。全虚拟化、半虚拟化和硬件辅助虚拟化描述不同实现方式；容器通常共享宿主内核，不等价于完整硬件虚拟机。

**例题。** 两个来宾 OS 各认为自己拥有从 0 开始的物理内存。VMM 如何避免它们映射到同一真实内存而互相覆盖？

**分析与逐步解答。** VMM 为每个来宾维护隔离的物理内存映射，拦截或辅助来宾页表操作，并把来宾“物理地址”进一步映射到机器真实地址；硬件二阶段页表可加速转换。权限检查确保一个来宾不能访问另一个来宾分配的页面。

**易错边界。** 虚拟机提供较完整硬件/内核隔离，容器主要隔离进程与资源但共享内核。Type 分类描述 VMM 运行位置，不直接代表安全性绝对高低。
