# 系统调用

## 概念、定义与适用条件

系统调用是用户程序请求操作系统内核服务的受控入口，如文件读写、进程创建和内存映射。调用通常由库函数封装：用户态执行陷入/系统调用指令后切换到内核态，内核检查参数与权限、执行服务、把结果或错误码返回用户态。库函数不一定一一对应系统调用；一个库函数可能不触发系统调用，也可能组合多个调用。

**例题。** 程序调用 `read(fd, buf, 100)`，说明它从用户态到内核态的基本过程以及返回值的含义。

**分析与逐步解答。** C 库先按 ABI 将文件描述符、缓冲区地址和长度放入约定位置，并执行系统调用指令。硬件切到内核态并进入系统调用分派入口；内核校验描述符、地址和访问权限，尝试读取数据，然后把实际读取字节数或错误状态返回。返回用户态后库函数把结果交给调用者。读取少于 100 字节并不必然是错误，需检查返回值和接口约定。

**易错边界。** 普通函数调用通常不改变特权级，系统调用会经过受控陷入；系统调用本身也不等同于中断。参数复制、阻塞和错误处理由具体 OS/ABI 决定。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
