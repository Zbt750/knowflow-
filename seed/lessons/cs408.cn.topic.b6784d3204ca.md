# UDP 协议

## 概念、定义与适用条件

UDP 提供无连接数据报服务，首部固定 8 Byte，含源端口、目的端口、长度和校验和。它不保证交付、顺序或去重，也不进行 TCP 式拥塞控制；应用可按需求自行处理。UDP 保留报文边界，适合对时延、组播或应用自定义控制有需求的场景，但网络仍可能丢包或重排。

**例题。** UDP 报文长度字段为 40 Byte，UDP 首部 8 Byte，应用数据长度是多少？IPv4 首部 20 Byte 时对应 IP 总长度是多少？

**分析与逐步解答。** UDP 长度包含 UDP 首部和数据，所以应用数据为 $40-8=32$ Byte。假设 IPv4 无选项且只承载该 UDP 报文，IP 总长度为 $20+40=60$ Byte。

**易错边界。** IPv4 UDP 校验和可为 0 表示未使用（IPv6 要求不同）；长度字段单位为字节。UDP 无连接不代表不需要端口或数据校验。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
