# 冒泡排序

## 概念、定义与适用条件

冒泡排序反复比较相邻元素并按次序交换。升序排序中，每趟把未排序部分的最大值推到末尾；若一趟没有交换，可提前结束。相邻交换不会颠倒相等元素原有先后，因此标准冒泡排序稳定；通常原地，平均和最坏时间复杂度 $O(n^2)$，已有序时加标志可达 $O(n)$。

**例题。** 对 `[3,1,2]` 做升序冒泡排序，列出每趟结果。

**分析与逐步解答。** 第一趟：比较 3 与 1 并交换得到 `[1,3,2]`；比较 3 与 2 再交换得到 `[1,2,3]`，最大值 3 到达末尾。第二趟扫描前两个数，1 与 2 顺序正确，没有交换，可判定整体有序并停止。总共两趟。

**易错边界。** 已确定的尾部区间无需重复扫描；相等元素不应交换，否则稳定性可能被破坏。复杂度结论依赖是否设置“本趟交换”标志。
