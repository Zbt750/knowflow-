# DMA 方式

## 概念、定义与适用条件

DMA 控制器在 CPU 初始化源/目的地址、传输长度和方向后，取得总线控制权并在外设与主存间搬运数据，完成后通常通知 CPU。DMA 减少 CPU 逐字搬运开销，但会与 CPU 竞争存储器/总线带宽；块传送、周期窃取等模式对总线占用方式不同。

**例题。** 设备向内存写入 4096 字节，DMA 每次传输 4 字节。忽略边界与突发，需完成多少次数据传送；若 CPU 只负责初始化和完成中断，谁负责中间数据搬运？

**分析与逐步解答。** 传输次数为 $4096/4=1024$ 次。中间数据由 DMA 控制器在设备接口与内存之间传送，CPU 不必对每个字执行读写指令；CPU 仍负责配置描述信息并处理完成或错误通知。

**易错边界。** DMA 不是不占总线；缓存一致性、地址映射和缓冲区生命周期也可能需要软件配合。若设备与主存间需跨越不同总线桥，路径和速率依系统结构而异。
