# DNS 系统

## 概念、定义与适用条件

DNS 是分布式、层次化的域名到资源记录映射系统。解析器可递归请求本地 DNS 服务器，也可由服务器迭代查询根、顶级域和权威服务器；结果按 TTL 缓存。A/AAAA 映射地址，CNAME 表示别名，MX 指向邮件交换服务器。DNS 传输常用 UDP，也在区域传送、截断或实现需要时使用 TCP。

**例题。** 客户端本地缓存中没有 `www.example.com`，递归解析器也没有缓存。简述一次典型解析链。

**分析与逐步解答。** 客户端向配置的递归解析器请求完整结果；解析器先问根服务器得到 `.com` 顶级域服务器，再问 `.com` 得到 `example.com` 权威服务器，最后向权威服务器查询主机记录并取得 A/AAAA 或 CNAME 链。解析器按 TTL 缓存并把结果返回客户端。实际可因缓存命中而跳过部分查询。

**易错边界。** 递归描述“替客户端完成查询”，迭代响应通常只给下一步服务器线索。DNS 名称解析不等于 TCP/HTTP 建连。
