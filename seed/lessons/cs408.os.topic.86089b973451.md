# 信号量

## 概念、定义与适用条件

信号量是由原子 P（等待/申请）与 V（释放/通知）操作访问的同步对象。计数信号量可表示多个同类资源；二值信号量常用于互斥。P 在资源不可用时阻塞调用者，V 可使等待者转为可运行。多个信号量操作的顺序决定系统能否正确同步，也可能引入死锁。

**例题。** 有界缓冲区容量为 2，初始 `empty=2, full=0, mutex=1`。生产者向空缓冲写入一个元素，按正确次序列出 P/V 操作并给出新值。

**分析与逐步解答。** 生产者先 `P(empty)`，empty 从 2 变 1；再 `P(mutex)` 进入临界区写数据；写完 `V(mutex)` 释放互斥锁，再 `V(full)` 表示多一个可读元素。最终 `empty=1, full=1, mutex=1`。实际阻塞队列状态还取决于并发进程。

**易错边界。** 生产者需先等待空槽再拿互斥锁，否则可能持锁阻塞而阻止消费者释放槽位。P/V 必须原子，初值和操作对象应与“资源数量”一致。
