# TCP 流量控制

## 概念、定义与适用条件

TCP 流量控制通过接收窗口 rwnd 限制发送方未确认数据量，避免接收端缓存溢出。接收端通告窗口约等于接收缓冲可用空间；发送方有效发送窗口还受拥塞窗口 cwnd 限制，即不超过两者较小值。窗口以字节序号描述，窗口更新与零窗口探测等机制需按协议约定理解。

**例题。** 接收端当前接收缓存大小 8000 Byte，已占用 3000 Byte，发送方 cwnd 为 7000 Byte。忽略已在途数据，rwnd 和新的发送上限分别是多少？

**分析与逐步解答。** 接收缓冲可用空间为 $8000-3000=5000$ Byte，所以 rwnd=5000 Byte。发送窗口受 `min(rwnd,cwnd)` 限制，为 5000 Byte。若还有未确认数据占用了窗口空间，新的数据可发送量还需再扣除在途字节数。

**易错边界。** rwnd 保护接收端，cwnd 约束网络拥塞；接收窗口为零不意味着 TCP 连接立即关闭。
