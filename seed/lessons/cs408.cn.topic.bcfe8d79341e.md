# 以太网 / IEEE802.3

## 概念、定义与适用条件

以太网定义局域网 MAC 层和物理层相关格式。常见以太网帧包含前导码/SFD、目的 MAC、源 MAC、类型或长度字段、数据与填充、FCS；最短帧长约束用于保证共享介质传统 CSMA/CD 能在发送期间检测碰撞。IEEE 802.3 与 Ethernet II 在类型/长度字段解释上有差异。

**例题。** 一个以太网帧的 MAC 数据字段不足最小要求，发送端为什么需要填充？填充是否属于上层有效数据？

**分析与逐步解答。** 发送端填充数据字段以满足最小帧长，使帧在共享介质早期以太网中能覆盖最大碰撞检测时间。填充属于链路层为帧格式加入的字节，不是上层 IP/TCP 的有效载荷；接收端通过上层长度字段或协议格式识别有效数据范围。

**易错边界。** 前导码/SFD 与帧长统计口径需按题面；FCS 通常在接收端校验并剥除。全双工交换以太网不使用传统 CSMA/CD 碰撞检测。

## 阅读总结

做题时明确协议层、单位和题设约定，逐步保留封装字段/状态或计算过程并检查边界；练习从该节点关联题库获取，本讲解不重复收录练习。
