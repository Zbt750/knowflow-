# CPU 调度基本概念

## 概念、定义与适用条件

CPU 调度在可运行实体中选择下一位占用处理器者。非抢占调度通常等当前进程主动阻塞或结束才换出；抢占式调度可在更高优先级任务到达或时间片用完时切换。评价指标包括 CPU 利用率、吞吐量、周转时间、等待时间、响应时间、公平性和截止期满足情况；不同目标可能冲突。

**例题。** 作业 A 到达时刻 0、服务时间 5，作业 B 到达时刻 2、服务时间 2；采用非抢占 FCFS。求两者周转时间、等待时间及 B 的响应时间。

**分析与逐步解答。** A 在 0 到 5 运行，B 在 5 到 7 运行。A 完成时刻 5，周转时间 $5-0=5$，等待时间 $5-5=0$。B 完成时刻 7，周转时间 $7-2=5$；其服务前等待 $5-2=3$，也等于周转时间减 CPU 服务时间；首次获得 CPU 时刻为 5，响应时间同为 $5-2=3$。

**易错边界。** 等待时间不含正在 CPU 上执行的服务时间；响应时间通常是首次响应减到达时刻。多级队列、I/O 突发等题目需把 CPU 与 I/O 时间线分开。
