# 计算机组成原理

## 本章导读与学习路径

计算机组成原理讨论软件可见的指令与数据如何由硬件表示、存储、传送和执行。做题时先固定机器约定：字长、地址单位、存储字节数、补码/浮点格式、流水级划分、Cache 参数以及 I/O 时序；题目未给出的约定不能自行补成唯一答案。再把抽象操作拆为位级表示、地址计算、部件状态变化或时钟周期，最后检查溢出、边界地址、冲突和控制条件。

建议沿“层次结构与性能 → 数值表示与运算 → 指令与 CPU → 存储器 → 总线和 I/O → 多处理器”学习。专题页分别讲明确切考点；虚拟存储器只讲地址转换与计组接口，页替换策略等操作系统内容以对应课程边界为准。节点来自当前知识树，属于本项目的学习组织，不构成官方考纲声明。

**贯通例题。** 某 8 位机器用补码表示有符号整数，执行 $70+60$。写出 8 位结果，并判断该结果能否解释为数学和。

**分析与逐步解答。** $70=01000110_2$，$60=00111100_2$。按 8 位相加：$01000110+00111100=10000010$。最高位为 1，若按补码解释是 $-126$；但两个正数相加的数学和为 130，超出 8 位补码范围 $[-128,127]$，所以发生有符号溢出，位串只是模 $2^8$ 的结果，不能当作精确数学和。判断溢出要看操作数和结果的符号关系，不能只看最高位进位。
