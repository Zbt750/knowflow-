# 进程状态与转换

## 概念、定义与适用条件

常见进程状态包括创建、就绪、运行、阻塞/等待和终止。就绪表示具备运行条件但等待 CPU；阻塞表示等待某事件或 I/O 完成，即使有空闲 CPU 也不能继续当前等待操作。运行进程可因时间片用完被抢占回就绪，也可因等待事件转入阻塞；事件完成则由阻塞转为就绪。

**例题。** P 正在运行时发起磁盘读，读完成前被调度器选中另一进程；设备完成后 P 的状态依次是什么？

**分析与逐步解答。** 发起同步磁盘读后，P 不能继续该操作，状态从运行转为阻塞；CPU 调度另一就绪进程运行。磁盘完成并发出通知后，P 由阻塞转为就绪，等待重新获得 CPU；它不会因 I/O 完成就直接成为运行态。

**易错边界。** 状态图可能把新建/挂起单列，名称和转换细节依模型；就绪队列不等于阻塞队列。进程退出后资源回收与父进程等待语义由系统接口决定。

## 阅读总结

做题时明确模型与题设约定，保留关键中间状态并检查边界条件；练习从该节点关联题库获取，本讲解不重复收录练习。
