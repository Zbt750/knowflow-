## 第一章 洛必达法则

### 适用条件

洛必达法则用于处理 0/0 型与无穷比无穷型未定式。使用前必须先判断未定式类型：只有当分子分母同时趋于零或同时趋于无穷时，才可能直接使用该法则。若把形如 1 的无穷次幂、0 乘无穷这类未定式直接套用，会得到错误的极限值。

法则成立的三个前提：在去心邻域内分子分母都可导；分母的导数在该邻域内不为零；导数之比的极限存在或为无穷。第三个条件最容易被忽略。若导数之比的极限不存在也不趋于无穷，法则失效，此时应改用其他方法，例如夹逼定理或有理化。

### 常见错误

第一类错误是不验证条件就求导。例如求 x 趋于零时 x 的平方乘以正弦 x 分之一再除以 x 的极限，分子分母求导后振荡加剧，导数之比不存在，但原极限其实为零。

第二类错误是反复使用后忘记检查是否仍是未定式。一旦导数之比变成非未定式，就必须停止求导并直接代入。继续求导会得到与真实极限无关的结果。

第三类错误是把洛必达法则用在数列极限上。数列没有导数，应先把离散变量换成连续变量，求出函数极限后再回到数列。

### 与等价无穷小配合使用

在实际计算中，洛必达法则往往与等价无穷小替换配合使用。先把乘积因子替换成等价的简单形式，再用洛必达法则处理剩下的未定式，可以显著减少求导次数与出错概率。注意在加减结构中不能直接替换，因为加减会放大高阶项的误差。

## 第二章 等价无穷小替换

### 常见等价无穷小

当 x 趋于零时，正弦 x 与 x 等价，正切 x 与 x 等价，一减余弦 x 与二分之一的 x 平方等价，对数一加 x 与 x 等价，指数 x 减一与 x 等价。这些等价关系都来自泰勒展开的首项，因此使用时的精度上限也是首项精度。

### 加减结构为什么不能直接替换

在加减结构中，两个等价量可能发生高阶抵消。例如求正切 x 减正弦 x 再除以 x 的三次方的极限时，若把正切 x 和正弦 x 都替换成 x，分子变成零，结论变成极限为零，这是错误的。正确做法是展开到三阶：正切 x 减正弦 x 的首个非零项是二分之一的 x 三次方，因此极限为二分之一。

判断能否替换的准则是：替换后的表达式与原表达式之差，必须是分子分母整体阶数的无穷小的高阶项。乘除结构天然满足这一条件，加减结构不满足，除非能确认不抵消。

## 第三章 隐函数求导

### 基本步骤

隐函数求导面对的是由方程确定的函数关系。步骤是：把方程两端同时对自变量求导，遇到因变量时按复合函数求导并乘上它的导数，最后把含导数的项移到一边解出导数表达式。

例如由方程 x 的平方加 y 的平方等于一确定的函数，两端求导得到 2x 加 2y 乘以 y 的导数等于零，于是 y 的导数等于负的 x 除以 y。这里必须注意 y 不为零的区间，因为在该点导数不存在。

### 用导数求切线方程

求出隐函数在某点的导数后，可以直接写出该点的切线方程。切线斜率为该点导数值，切线方程由点斜式给出。对于上面那个单位圆，在横坐标等于二分之根号二处，纵坐标也等于二分之根号二，导数值为负一，切线方程可整理为两坐标之和等于根号二。

求切线时容易犯的错误是把因变量的值代错。隐函数给出的点必须同时满足原方程，代入前应先验证。

### 与参数方程求导的区别

参数方程求导是把纵坐标与横坐标分别对参数求导，再取比值。隐函数求导不对参数求导，而是直接对自变量求导。两者的共同点是都必须把因变量当成自变量的函数处理，区别只在中间变量的选择。

## 第四章 等比级数的敛散性与求和

### 收敛条件

等比级数是从首项开始每项乘以固定公比得到的级数。当公比的绝对值小于一时，部分和收敛，级数收敛；当公比的绝对值大于等于一时，部分和不收敛，级数发散。公比等于负一时，部分和在两个值之间跳动，同样发散。

判断任何级数是否收敛之前，先看通项是否趋于零。通项不趋于零的级数一定发散，这一步只需要几秒钟，却能避免后续大量无效计算。

### 求和公式

级数收敛时，和等于首项除以一减公比。使用公式前必须确认公比的绝对值小于一，否则公式给出的是形式上的代数结果，与级数的和没有任何关系。

当级数不是从零次幂开始时，首项是级数中指数最小的那一项，而不是随便取的一项。把首项取错是最常见的计算失误。

### 与其他判别法的关系

等比级数是最基础的参照级数。比较判别法就是把待判级数与等比级数比较；根值判别法与比值判别法都是通过极限把级数归到等比级数的敛散性上。因此熟练掌握等比级数的收敛条件，是掌握所有判别法的前提。

## 第五章 行列式的性质

### 对换性质

交换行列式的两行或两列，行列式变号。由此可以推出：若行列式有两行完全相同，则行列式为零，因为交换这两行后行列式不变号又变号，只能为零。这条推论在判断向量组线性相关性时经常使用。

### 数乘与可逆

用一个数乘以行列式的某一行，等于行列式乘以这个数。对于 n 阶方阵，整体数乘 k 倍时，行列式变为 k 的 n 次方倍，因为每一行都乘了 k。这个指数 n 是最容易漏掉的地方。

方阵可逆的充要条件是行列式不为零。可逆时，逆矩阵的行列式等于原行列式的倒数。因此行列式为零的方阵一定不可逆，与之相关的线性方程组要么无解要么有无穷多解。

### 乘积的行列式

两个同阶方阵乘积的行列式等于各自行列式的乘积。这条性质把矩阵乘法与数的乘法联系起来，是计算抽象行列式的主要工具。

需要注意的是这条性质只对方阵成立。非方阵没有行列式，也就谈不上乘积的行列式。
